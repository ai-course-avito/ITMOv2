# Среда агента: обоснование подключений

## AGENTS.md
**Зачем:** указать агенту минимальный маршрут чтения и границы изменений.
**Как улучшает:** агент не лезет в лишние файлы, читает только нужное, 
ссылается на источники (file:line). Без него — галлюцинации о структуре проекта.

## Skill pptx
**Зачем:** генерировать презентации .pptx без ручного редактирования XML.
**Как улучшает:** агент использует готовые скрипты (`thumbnail.py`, `validate.py`), 
а не пишет XML вручную. Результат — output.pptx с 8 слайдами.

## MCP context7
**Зачем:** получать актуальную документацию библиотек (python-pptx) прямо в чате.
**Как улучшает:** при работе над `check_pptx.py` агент через context7 нашёл 
документацию по `shape.text` и `has_text_frame`, проверил корректность кода. 
Без MCP — пришлось бы искать доки вручную или гадать.

## MCP pptx-reader (собственный)
**Зачем:** собственный tool для чтения слайдов без запуска полного скрипта.
**Как улучшает:** агент может быстро узнать число слайдов и заголовок 
через `count_slides` и `get_slide_title`, не запуская `check_pptx.py`.

## Hook check-after-edit (pre-commit)
**Зачем:** автоматически запускать `make check` (ruff + тесты + check_pptx) 
перед коммитом.
**Как улучшает:** поймал 6 ошибок ruff в `check_pptx.py`, коммит заблокировался. 
Без hook'а ошибки ушли бы в репозиторий.
