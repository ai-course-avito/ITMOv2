# Smart Search: Proposal

## Why
Репозиторий ITMOv2 содержит учебные практики, тесты, инструкции и конфигурации. Быстрый «умный» поиск по проекту помогает:
- находить релевантный код и артефакты без скролла по дереву,
- подтверждать факты ссылками `file:line` и контекстом,
- избегать ложных выводов («нет данных») по согласованному формату.

Это важно для домашки практики 4: проверка своих проектов, подготовка эталонов и разбор ограничений. Команда `/smart-search` стандартизирует поиск и вывод.

## Goals
- Единая команда для поиска по всему репо.
- Согласованный формат ответа с приоритетами и лимитами.
- Безопасно: только чтение (read/glob/grep), без записи.

## Non-Goals
- Индексация, кеширование, интеграции с внешними сервисами.
- Изменение кода практик 1–4 или demo/.

## Success Criteria
- Найдёт целевые файлы и участки по демо‑сценариям (check_pptx, pptx-reader).
- Корректно вернёт негативный ответ при отсутствии совпадений.
- Вывод читабелен и содержит обоснование.
