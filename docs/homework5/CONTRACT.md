# Общий контракт: Report Exporter (/export-report)

## 1. Стыковка спек
- **UI (Spec Kit):** описывает интерактив (вопросы про формат MD/HTML и состав).
- **Logic (Kiro):** описывает парсинг JSON, генерацию таблицы и сохранение.

## 2. Решения по конфликтам
- **Формат:** UI спрашивает "Markdown или HTML". Logic поддерживает оба. UI передает выбранный `format` в Logic.
- **Состав:** UI спрашивает "Только метрики или с артефактами". Logic читает `prompts.md` и `REPORT.md` только если передан флаг `include_artifacts=true`.
- **Ошибки:** Logic возвращает пустой массив, если нет данных. UI перехватывает это и выводит ровно "Нет данных для отчёта".
- **Сортировка:** Logic сортирует файлы по алфавиту (FR-L12). UI просто отображает то, что вернул Logic.

## 3. Как проверяем (Сквозной сценарий)
1. Запускаем `/export-report`.
2. Выбираем "Markdown" и "С артефактами".
3. Проверяем, что создался `reports/report-2026-10-22.md`.
4. Внутри есть таблица с метриками (wall_seconds, decode_tokens_per_second) и содержимое `prompts.md`.
5. Если удалить все JSON из `lab/results/`, команда выводит "Нет данных для отчёта" и файл не создается.
