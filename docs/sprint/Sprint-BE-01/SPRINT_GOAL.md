# Sprint BE-01 - Goal

Дата: 2026-10-28

Цель: Реализовать бекенд-слой игрификации: профили с уникальными именами, лимиты круток (5/день) и сброс по полуночи (UTC + смещение), пул и результат спина с редкостью 85/10/5 и гарантией ≥1 эмодзи, правила дублей (игнор + сообщение), перк «мульти-эмодзи» (до 3), каталог эмодзи (код+версия), миграция JSON→БД (пропуск + отчёт, отклонение дублей имён).

Критерии завершения:
- Создание/получение профиля по имени с уникальностью; хранение лимитов и перков.
- Выдача пула призов на раунд с ≥1 эмодзи; редкость 85/10/5; генерация результата спина.
- Учёт лимитов: 5/день; сброс в полночь локального времени (UTC + смещение).
- Обработка дублей эмодзи: «игнор + сообщение».
- Перк «мульти-эмодзи»: включение/учёт до 3 эмодзи/задачу.
- Миграция: перенос JSON→БД, отчёт о пропусках/дублях.
