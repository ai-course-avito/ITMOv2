# Sprint UI-01 - Goal

Дата: 2026-10-28

Цель: Доставить UI-слой игрификации: кнопка «ИГРАТЬ», визуал и анимация колеса (мин. 8 сегментов, визуально ≥1 эмодзи), отображение результатов спина и сообщений о дублях, полноэкранный баннер при 0 круток, выбор эмодзи при создании/редактировании задач, состояния «добавить ещё эмодзи».

Критерии завершения:
- На главном экране есть заметная кнопка «ИГРАТЬ»; при 0 круток нажимается → баннер.
- Экран/оверлей колеса: анимация, визуализация пула с ≥1 эмодзи, нейтральные визуальные эффекты.
- Показ результата спина; при дубле — сообщение без изменения статуса эмодзи.
- Выбор эмодзи в форме создания/редактирования задач: доступные видны, недоступные серым (или скрыты); отображение эмодзи перед задачей.
- «Добавить ещё эмодзи»: неактивно без перка; до 3 — при активном перке.
