# UI Specification

Feature: Игрификация задач: колесо фортуны и эмодзи (UI)
Created: 2026-10-28

## Scope

- Отображение и поведение кнопки «ИГРАТЬ» на главном экране (правый верхний угол), яркое визуальное выделение.
- Экран/оверлей «колеса фортуны»: анимация, визуал пулла призов (мин. 8 сегментов), гарантированно ≥1 эмодзи; нейтральные визуальные эффекты без намёка на «подкрутку».
- Отображение результата спина; коммуникация дублей («игнор + сообщение»).
- Полноэкранный баннер при исчерпании 5 круток/день; кнопка «ИГРАТЬ» при клике ведёт к баннеру.
- Выбор эмодзи при создании/редактировании задач: 
  - элемент управления добавлением эмодзи, 
  - список эмодзи из каталога: доступные — обычные, недоступные — серым (если возможно) или скрыты, 
  - отображение эмодзи перед задачей.
- Состояния «добавить ещё эмодзи»: 
  - без перка «мульти-эмодзи» — неактивно (с подсказкой), 
  - с перком — возможность добавить до 3 эмодзи на задачу.

## Inputs (from Backend)

- Профиль пользователя: уникальное имя, остаток круток, отметка о перке «мульти-эмодзи», список доступных эмодзи (код+версия), время до сброса.
- Каталог эмодзи: код+версия, отображение, редкость.
- Пул призов текущего раунда (для визуализации колеса).
- Результат спина и его тип (эмодзи/прочее) и детализация.

## Outputs (to Backend)

- Запрос на вход по имени (создание профиля при первом входе).
- Запрос на формирование/получение пула призов для раунда.
- Запрос на запуск спина и получение результата.
- Действия над задачами: назначение/снятие эмодзи, попытка добавления дополнительных эмодзи при наличии перка.

## Acceptance Mapping (UI)

- FR-002: Кнопка «ИГРАТЬ» — визуальная доступность/недоступность.
- FR-003 (UI): Отображение колеса и состав пулла; названия/иконки призов; анимация.
- FR-004 (UI): Показ результата и визуальная фиксация уменьшения лимита.
- FR-006/006a/006b: Выбор эмодзи при создании/редактировании; серые/скрытые недоступные.
- FR-007: Полноэкранный баннер при 0 круток.
- FR-012: Гарантия визуального наличия ≥1 эмодзи в колесе.
- FR-014a: Неактивная кнопка «добавить ещё эмодзи» без перка; до 3 с перком.
- FR-015 (UI): Шутливые призы — визуальные/тексты без эффектов.

## Non-Goals (UI)

- Управление вероятностями и редкостью, хранение данных, сбросы лимитов — ответственность Backend.
- Платёжные/финансовые операции отсутствуют.
