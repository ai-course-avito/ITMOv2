# Invariants

- Лимит спинов: 5 в сутки; сброс в полночь локального времени (UTC + текущее смещение).
- Пул для колеса: минимум 8 сегментов; обязательно ≥1 сегмент с эмодзи.
- Дубли эмодзи: правило «игнор + сообщение» — спин засчитывается, набор эмодзи не изменяется.
- Перк «мульти-эмодзи»: по умолчанию 1 эмодзи/задачу; при активном перке — до 3.
- Каталог эмодзи: хранение в код + версия; визуальная отрисовка на UI.
