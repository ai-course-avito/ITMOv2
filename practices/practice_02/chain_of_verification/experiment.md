## Запрос на проверку


"Проверь согласованность требований: 1) таймаут 1500 мс на внешний геокодер — не конфликтует ли с целями mobile-first? 2) при недоступности Redis — корректно ли ожидать отсутствие 5xx? 3) допустимо ли маркировать результат как частичный? Предложи правки, если формулировки двусмысленны."

## Вопросы и результаты проверки

| Вопрос | Источник или проверка | Результат |
|---|---|---|
| 1500 мс для внешнего API приемлемо? | Сравнение с типичными SLO для cold path мобильных API | Приемлемо для cold path; кэшированный путь остаётся <100 мс |
| Без 5xx при недоступном Redis не скрывает ли сбои? | Принцип graceful degradation для кэша | 200/206 с логированием деградации приемлемы |
| Маркировать результат как частичный — не нарушит ли контракт? | Проверка схемы ответа: наличие поля метаданных | Допустимо при наличии статуса в ответе |

## Исправленный результат

Уточнили: таймаут не отменяет основной ответ из локальных источников; при недоступности Redis — degraded mode с логированием; добавлено требование о наличии статуса результата (полный/частичный) в ответе API.
