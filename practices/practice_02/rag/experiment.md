- Вопрос к источникам:
  Какой TTL и поведение кэша заданы в Context Pack Практики 1, и есть ли указания по Redis и геокодеру?

## Запрос

"Извлеки из разрешённых источников упоминания о Redis, кэшировании, внешнем геокодере, SLO/TTL. Сопоставь с текущими сценариями и предложи консистентные значения (например, TTL 600с)."

## Ответ со ссылками на источники

В Context Pack указано: «Кэш: Redis для частых запросов координат и результатов поиска (mobile-first латентность)». Конкретный TTL не указан — выбрали 600 секунд как разумный baseline для координат. Используются внешние геокодеры через httpx; строгая типизация DTO (Pydantic) — значит, пометка статуса в ответе допустима.
