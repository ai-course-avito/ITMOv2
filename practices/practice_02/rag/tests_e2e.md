# E2E-проверки

| Сценарий | Предусловия | Действие | Наблюдаемый результат | Evidence |
|---|---|---|---|---|
| Успешный POST с валидным `diff` (AS IS) | Сервис запущен; доступен POST `/api/reviews` | Отправить POST `/api/reviews` с JSON `{ "diff": "diff --git a/x b/x\n+line" }` | 200 OK; тело JSON содержит ключ `comment` со строковым значением | TRAINING_PR.diff: app/api.py 35–37; app/review_service.py 19–22; context.md 24–26, 34 |
| Отсутствует ключ `diff` | Сервис запущен | Отправить POST `/api/reviews` с пустым телом `{}` или без ключа `diff` | При обращении к `payload["diff"]` возникает `KeyError("diff")` (ошибка обработки запроса) | TRAINING_PR.diff: app/api.py 35–37; context.md 10, 38; problem.md 7–8 |
| Слишком длинный `diff` | Сервис запущен | Отправить POST `/api/reviews` с `diff` длиннее 20 000 символов | 413 Payload Too Large | CASE.md: правило API-1 |
| Маскировка секретов в prompt | Сервис запущен | Отправить POST `/api/reviews` с `diff`, содержащим тестовый токен/секрет (напр. `token=...`) | Секреты удалены/замаскированы перед отправкой во внешний LLM; проверка: в сформированном prompt вместо секрета `[REDACTED]` | CASE.md: правило SEC-1; CASE.md: пример проверки 81–85 |
| Таймаут внешнего LLM | Сервис запущен; внешнее LLM симулирует задержку >10 секунд | Отправить POST `/api/reviews` во время таймаута LLM | Возвращается контролируемый ответ без необработанного исключения; применяется таймаут 10 секунд | CASE.md: правило REL-1 |
| Логирование без содержимого | Сервис запущен; доступ к логам | Выполнить POST `/api/reviews` | В логах есть только `request_id`, длительность и статус; содержимое `diff` и ответа модели не логируется | CASE.md: правило OBS-1 |
| Формат ответа по правилам репозитория | Сервис запущен | Отправить POST `/api/reviews` с валидным `diff` | Тело ответа содержит `summary`, массив `risks` (≤3) с полями `file`, `line`, `evidence`, `risk`, и массив `checks` | CASE.md: правило OUT-1 |

## Источники и доказательства

- TRAINING_PR.diff:
  - app/api.py 35–37 — эндпоинт POST `/api/reviews`, прямой доступ к `payload["diff"]`.
  - app/review_service.py 19–22 — формирование prompt и возврат `{"comment": answer}`.
- context.md:
  - 24–26 — формат результата `{ "comment": "..." }`.
  - 34 — пример успешного запроса с 200 OK.
  - 10, 38 — риск `KeyError("diff")` при отсутствии поля `diff`.
- problem.md:
  - 7–8 — текущее поведение: прямой доступ к `payload["diff"]` ведёт к `KeyError` и вероятному 500.
- CASE.md (правила репозитория):
  - SEC-1 — удаление секретов перед отправкой во внешний LLM; пример проверки 81–85.
  - API-1 — `diff` > 20 000 символов → HTTP 413.
  - REL-1 — таймаут внешнего LLM 10 секунд; ошибка превращается в контролируемый ответ.
  - OUT-1 — формат ответа: `summary`, `risks` (≤3, с полями `file`, `line`, `evidence`, `risk`), `checks`.
  - OBS-1 — логируются только `request_id`, длительность и статус; контент не логируется.
