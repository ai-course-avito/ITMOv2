# E2E-проверки (RCTF)

| Сценарий | Предусловия | Действие | Наблюдаемый результат | Evidence |
|---|---|---|---|---|
| Позитивный: корректный diff | Сервис запущен; доступен POST `/api/reviews`; LLM замокан и возвращает строку | Отправить JSON `{"diff":"diff --git a/x b/x\n+ok"}` | 200 OK; тело `{ "comment": "..." }` | HTTP 200; поле `$.comment` — непустая строка; лог содержит строку вида `request_id=<uuid> status=200 duration=<ms>` и не содержит подстроку `diff --git` |
| Негативный: отсутствует ключ `diff` | Сервис запущен; доступен POST `/api/reviews` | Отправить JSON `{}` | 422 Unprocessable Entity; тело содержит описание обязательного поля `diff` | HTTP 422; поле `$.detail` упоминает `diff`; лог содержит `request_id=<uuid> status=422 duration=<ms>` и не содержит подстроку `diff --git` |
| Граничный: длина diff ровно 20000 | Сервис запущен; доступен POST `/api/reviews`; LLM замокан | Отправить JSON с `diff` длиной ровно 20000 символов | 200 OK (граница допустима по CASE API‑1: «больше 20000» → 413); тело `{ "comment": "..." }` | HTTP 200; поле `$.comment` — непустая строка; лог содержит строку `request_id=<uuid> status=200 duration=<ms>` и не содержит подстроку `diff --git` |
| Негативный: diff длиннее 20000 символов | Сервис запущен; доступен POST `/api/reviews` | Отправить JSON с `diff` длиной 20001 символ | 413 Payload Too Large (API‑1) | HTTP 413; лог содержит `request_id=<uuid> status=413 duration=<ms>` и не содержит подстроку `diff --git` |
