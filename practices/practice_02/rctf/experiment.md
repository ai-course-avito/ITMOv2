# R.C.T.F.

- **Role:** инженер по производительности (performance engineer), отвечающий за нефункциональные требования сервиса `/api/reviews`.
- **Context:** правило `REL-1` — внешний LLM-вызов имеет timeout 10 секунд, ошибка превращается в контролируемый ответ; правило `API-1` — `diff` длиннее 20 000 символов отклоняется с HTTP 413 (оба из [`CASE.md`](../../practice_01/CASE.md)). Текущая таблица в [`tests_load.md`](../../practice_01/tests_load.md) задаёт `p95 latency ≤ 12с` без объяснения, откуда взялось число 12, и `error rate ≤ 1%` без ссылки на источник.
- **Task:** пересчитать допустимые пределы (`p95 latency`, `error rate`) как явную формулу от правил `REL-1`/`API-1` и метрик `problem.md`, а не как произвольные числа.
- **Format:** таблица с дополнительной колонкой «Источник предела», без прозы.

## Полный запрос

```text
Ты performance-инженер сервиса /api/reviews. Контекст: REL-1 задаёт timeout LLM-вызова
10 секунд, API-1 ограничивает diff 20000 символами. Задача: для каждого предела в таблице
нагрузочных сценариев tests_load.md выведи формулу расчёта из REL-1/API-1 и метрик problem.md,
без произвольных чисел. Формат: таблица со столбцом «Источник предела», без пояснительного
текста вне таблицы.
```

## Что получили

| Предел | Значение | Источник предела |
|---|---|---|
| p95 latency | ≤ 12с | `REL-1` (timeout LLM 10с) + ~2с накладных расходов на валидацию входа и сеть |
| Доля 5xx | ≤ 1% | `problem.md`, таблица метрик, строка «Доля запросов с 5xx на `/api/reviews`» |
| Размер `diff` в сценариях | ровно 20 000 символов (граничный сценарий) | `API-1`, `CASE.md` |

## Что изменили в исходном артефакте

- Файл и раздел: [`tests_load.md`](../../practice_01/tests_load.md), таблица сценариев — добавлен столбец «Источник предела». Итоговая копия изменённого файла приложена рядом: [`tests_load.md`](tests_load.md).
- Изменение: `p95 ≤ 12с` теперь явно выведен как `timeout(REL-1) + overhead`, а не константа; `доля 5xx ≤ 1%` явно сослан на строку метрики в `problem.md`.
- Как проверили: для каждого числа в таблице есть либо правило (`REL-1`/`API-1`), либо конкретная строка `problem.md` — без чисел без источника.
- Что отклонили: предложение поднять `p95` до 15с «про запас» — отклонено, потому что не выводится ни из одного правила и увеличивает риск маскировать реальные regressions.
