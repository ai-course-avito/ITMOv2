    Что хотим улучшить: переписать свободный текст нагрузочных проверок в воспроизводимые Gherkin-сценарии

Запрос (RCTF)

Role: ты QA-инженер, специализирующийся на нагрузочном тестировании и BDD-спецификациях.

Context:

    Целевой файл: practices/practice_01/tests_load.md, раздел «Нагрузочные сценарии».

    Стиль и правила: CASE.md (SEC-1, API-1, REL-1, OUT-1).

    Метрики и пороги: problem.md.

    Язык: русский.

Task:

    Прочитай свободный текст нагрузочных проверок.

    Для каждой проверки выдели: входные данные, действие, ожидаемый результат, метрику.

    Сконвертируй в Gherkin, используя Given/When/Then.

    Убери риторику, оставь только воспроизводимые шаги.

    Явно привяжи ожидания к правилам CASE.md и метрикам problem.md.

Format:

    Только Gherkin-блоки, по одному сценарию на проверку.

    Заголовок сценария: Scenario: <краткое имя>.

    Тело: строго Given … / When … / Then …, без вводных фраз.

    Опционально: теги @SEC-1, @API-1, @REL-1, @OUT-1.

    В конце — короткий список «Покрытие правил» (какое правило каким сценарием закрыто).

    Без вступлений и пояснений вне указанного формата.
