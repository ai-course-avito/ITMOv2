# R.C.T.F.

- **Role:** системный архитектор учебного API-review сервиса.
- **Context:** `TRAINING_PR.diff` и правила `SEC-1`–`OBS-1`; иных источников нет.
- **Task:** предложить минимальное решение, закрывающее правила без лишней инфраструктуры.
- **Format:** контекст, решение, альтернативы, последствия, риск, Mermaid-схема.

## Полный запрос

Ты системный архитектор. По `TRAINING_PR.diff` и релевантным правилам `CASE.md` подготовь краткий ADR. Выбери минимальное решение, не предполагая auth, БД или GitHub-интеграцию. Верни разделы: Контекст, Решение, 3 альтернативы, Последствия, Главный риск, Mermaid.

## Что получили

Синхронный pipeline: validation → redaction → LLM с timeout → проверка схемы → безопасный лог.

## Что изменили в исходном артефакте

- Файл и раздел: `../practice_01/adr.md`, «Контекст» и «Решение».
- Изменение: решение ограничено одним HTTP-сценарием и правилами кейса.
- Как проверили: каждый этап сопоставлен с ID правила.
- Что отклонили: auth, хранилище результатов и GitHub API — источники их не требуют.
