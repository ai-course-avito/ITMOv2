# R.C.T.F.

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- **Role:** Product Manager + Backend Architect
- **Context:** AnimeMap API, FastAPI + PostgreSQL + Redis; внешний геокодер (Nominatim) с лимитами; требуется уточнить поведение при 429 и negative cache.
- **Task:** Предложить Gherkin-сценарии для обработки 429 (rate limit), без агрессивных ретраев; описать negative cache на ограниченное время.
- **Format:** Короткие сценарии Gherkin с проверяемыми шагами, без скрытых деталей реализации.

## Полный запрос


"Сформулируй для product_management.md два Gherkin-сценария: 1) внешний геокодер возвращает 429; система не ретраит немедленно, сообщает пользователю о лимите, и кэширует отрицательный результат (negative cache) на короткий срок; 2) уточнение квоты: при остатке <10% система понижает частоту обращений. Не добавляй реализацию, только поведение."

## Что получили

Два сценария: "Лимит запросов внешнего геокодера (429)" с сообщением пользователю и кэшированием отрицательного результата на 60 секунд; указанием не выполнять немедленные ретраи. Уточнение о низком остатке квоты (<10%).
