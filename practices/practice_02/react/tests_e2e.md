# E2E-проверки

| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Evidence |
|---|---|---|---|---|
| Пользователь отправляет diff и получает ответ | Сервис запущен; доступен POST `/api/reviews`; LLM замокан | Отправить `{"diff": "diff --git a/x b/x\n+line"}` | 200 OK; тело с полями `summary`, `risks` (<=3), `checks`; поля в risks заполнены | логи / тест-раннер |
| Длинный diff отклоняется (API-1) | Сервис запущен | Отправить тело, где `diff` длиной > 20 000 символов | 413 Payload Too Large | HTTP статус / ответ |
| Граница длины проходит (API-1, =20000) | Сервис запущен | Отправить тело, где `diff` длиной ровно 20 000 символов | 200 OK | HTTP статус |
| Ответ соответствует контракту OUT-1 | Сервис запущен; LLM замокан | Отправить валидный `diff` | 200 OK; тело с полями `summary`, `risks`, `checks`; в `risks` не более 3 элементов, каждый содержит `file`, `line`, `evidence`, `risk` | схема ответа / ассерты |
| Кэп рисков = 3 (OUT-1) | Сервис запущен; LLM замокан возвращает >=4 риска | Отправить валидный `diff` | 200 OK; в ответе не более 3 рисков | ассерты по длине массива |
| Редакция секретов перед LLM (SEC-1) | Сервис запущен; LLM замокан с захватом prompt | Отправить `diff` с тестовыми секретами (token, password, приватный ключ) | LLM вызывается с prompt, где секреты заменены на `[REDACTED]`; в ответе сервиса секреты не утекли | захваченный prompt LLM |
| Таймаут/ошибка LLM → контролируемый ответ (REL-1) | Сервис запущен; LLM замокан на таймаут >10с или выброс ошибки | Отправить валидный `diff` | Запрос не падает; по истечении ≤10с возвращается контролируемый ответ (стабильный статус и предсказуемое тело по контракту) | метрики времени, статус/тело ответа |
| Логи без содержимого diff и ответа (OBS-1) | Сервис запущен; включён сбор логов | Отправить валидный `diff` | В логах присутствуют только `request_id`, длительность и статус; содержимое `diff` и ответ модели отсутствуют | сбор логов |
