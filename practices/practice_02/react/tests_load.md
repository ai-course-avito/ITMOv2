## Финальный Gherkin

```gherkin
@API-1
Scenario: Смесь E2E 422/413/200 под нагрузкой
  Given профиль нагрузки 3 RPS в течение 10 минут
  And 30% тел без поля diff, 20% с diff длиной 20001, 50% валидных
  When отправляем POST "/api/reviews"
  Then доля 422 ≈ 30%, 413 ≈ 20%, 200 ≈ 50%
  And P95 по каждому коду ≤ 1.5 с, 5xx = 0

@OUT-1
Scenario: Позитивный E2E при базовой нагрузке
  Given профиль нагрузки 2 RPS в течение 5 минут
  When отправляем валидные тела
  Then P95 ≤ 500 мс и ответ соответствует OUT-1

@API-1
Scenario: Нет diff → 422 под нагрузкой
  Given профиль нагрузки 2 RPS в течение 5 минут
  And 30% тел без поля diff
  When отправляем POST "/api/reviews"
  Then доля 422 = 30% ± 2% и 5xx = 0
```
