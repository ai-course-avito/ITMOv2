# ReAct

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Цель:
  Добавить сценарий degraded mode при недоступности Redis без изменения других разделов.
- Доступные входы:
  product_management.md, контекст из practice_01/context.md.
- Разрешённые действия:
  читать файлы, редактировать раздел Gherkin, обновлять experiment.md.
- Запрещённые действия:
  менять другие артефакты, добавлять нерелевантные требования.
- Максимальное число шагов:
  3
- Условие остановки и вопроса человеку:
  если нет упоминания Redis недоступен — добавить сценарий; иначе спросить, нужно ли менять текущее поведение.

"Проверь, есть ли сценарий поведения при недоступности Redis. Если нет — добавь краткий сценарий degraded mode: обход кэша, успешный ответ без 5xx, лог деградации."
