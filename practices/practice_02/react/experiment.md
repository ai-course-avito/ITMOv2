# ReAct

- Цель: найти и исправить противоречия в SDLC-артефактах без изменения кода и без сетевых действий.
- Доступные входы: CASE.md, TRAINING_PR.diff, `practice_01/problem.md` и файлы текущего эксперимента.
- Разрешённые действия: чтение разрешённых файлов, поиск по репозиторию, правка только перечисленных Markdown-файлов, `make step2`, `git diff --check`.
- Запрещённые действия: HTTP-запросы, внешний LLM, изменение кода/README/Makefile/TRAINING_PR.diff, commit/push/merge.
- Максимальное число шагов: 6.
- Условие остановки и вопроса человеку: остановиться после успешных `make step2` и `git diff --check`; запросить человека, если нужна сеть, код или файл вне allowlist.

## Запрос

Работай максимум в шесть шагов. Прочитай CASE.md, TRAINING_PR.diff и `practice_01/problem.md`; найди старые лимиты и неподтверждённые результаты; исправляй только `practice_01/problem.md` и файлы экспериментов Практики 2; затем выполни `make step2` и `git diff --check`. Для каждого шага верни действие, фактическое наблюдение и решение продолжить/остановиться. Не используй сеть, внешний LLM и файлы вне allowlist.
