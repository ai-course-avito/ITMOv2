# ReAct

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Цель: финальный контролируемый проход по `problem.md` без ложных runtime-утверждений.
- Доступные входы: `practices/practice_01/problem.md`, `practices/practice_01/TRAINING_PR.diff`, `practices/practice_01/context.md`, все `practices/practice_02/*/experiment.md`, `practices/practice_02/prompts.md`.
- Разрешённые действия: чтение файлов, сопоставление утверждений с источниками, поиск противоречий, правка `problem.md`, правка `react/experiment.md` и `prompts.md`, запуск `git diff --check`, запуск `make step2`.
- Запрещённые действия: изменение `TRAINING_PR.diff`, создание каталога `app/`, изменения исходного кода учебного приложения, заявления о выполненных runtime-тестах, использование внешних источников, выдумывание SLA/HTTP-кодов/порогов, превращение гипотез в факты.
- Максимальное число шагов: 6.
- Условие остановки и вопроса человеку: если утверждение нельзя подтвердить доступными материалами, классифицировать как неизвестное/требующее runtime-проверки/согласования и остановиться на правке без додумывания.
