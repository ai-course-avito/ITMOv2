    Артефакт Практики 1: practices/practice_01/tests_load.md — раздел «Нагрузочные сценарии»

    Что хотим улучшить: переписать свободный текст нагрузочных проверок в воспроизводимые Gherkin-сценарии

Запрос (ReAct)

Сконвертируй нагрузочные проверки для tests_load.md из свободного текста в Gherkin.
Используй Given/When/Then, на русском, минимизируй риторику.
Выравняй с правилами CASE.md (SEC-1, API-1, REL-1, OUT-1) и метриками из problem.md.

Работай в цикле Thought → Action → Observation:

    Thought: что нужно сделать на текущем шаге (прочитать, извлечь, преобразовать, проверить).

    Action: конкретное действие (чтение файла, поиск правила, запись сценария, проверка метрики).

    Observation: что получено (фрагмент текста, формулировка правила, значение метрики, черновик сценария).

Повторяй цикл, пока не будут выполнены условия:

    все нагрузочные проверки покрыты;

    каждый сценарий соответствует Given/When/Then и не содержит риторики;

    каждое правило SEC-1, API-1, REL-1, OUT-1 закрыто хотя бы одним сценарием;

    каждая метрика из problem.md присутствует в ожиданиях.

Формат вывода:

    Журнал шагов Thought/Action/Observation.

    Финальный блок Gherkin.

    Блок «Проверка условий» (чек-лист покрытия).
