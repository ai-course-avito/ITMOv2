# ReAct

- Цель: дополнить `tests_e2e.md` до полного E2E-покрытия POST `/api/reviews` по правилам CASE.
- Доступные входы: TRAINING_PR.diff, context.md, problem.md, CASE.md.
- Разрешённые действия: читать источники, проверять утверждения, задавать вопросы, останавливаться при достижении цели.
- Запрещённые действия: придумывать сценарии без подтверждения; выходить за scope (GitHub, БД, auth).
- Максимальное число шагов: 8 циклов.
- Условие остановки и вопроса человеку: все правила CASE покрыты, либо после 8 циклов остались непокрытые пункты.

## Запрос

Через цикл Thought → Action → Observation дополни tests_e2e.md до полного E2E-покрытия POST /api/reviews. Для каждого сценария — обоснование через Observation из источника.

## Наблюдаемые действия и результаты

| Шаг | Действие | Наблюдение | Решение продолжить или остановиться |
|---|---|---|---|
| 1 | Читаю TRAINING_PR.diff (app/api.py, app/review_service.py) | Эндпоинт POST /api/reviews, возвращает `{"comment": ...}` | Продолжить: контракт AS IS |
| 2 | Читаю CASE.md (OUT-1) | Целевой ответ: summary, risks (≤3), checks | Продолжить: нужно покрыть OUT-1 |
| 3 | Читаю CASE.md (API-1) | diff > 20000 → 413 | Добавить сценарии 413 и границу 20000 |
| 4 | Читаю CASE.md (SEC-1) | Секреты редактируются перед LLM | Добавить сценарий с проверкой prompt |
| 5 | Читаю CASE.md (REL-1) | Таймаут LLM 10с → контролируемый ответ | Добавить сценарий таймаута |
| 6 | Читаю CASE.md (OBS-1) | Логи: request_id, длительность, статус без содержимого | Добавить сценарий проверки логов |
| 7 | Проверяю покрытие правил по CASE.md (SEC-1, API-1, REL-1, OUT-1, OBS-1) | Все правила покрыты | Остановиться: цель достигнута |

## Что изменили в исходном артефакте

- Файл и раздел: `react/tests_e2e.md`, таблица сценариев
- Изменение: было 1 сценарий → стало 8 (успех, 413, граница 20000, OUT-1, кэп risks=3, SEC-1, REL-1, OBS-1)
- Как проверили: каждый сценарий обоснован Observation из TRAINING_PR.diff или CASE.md
- Что отклонили: сценарии с реальным LLM, GitHub, БД, auth — вне scope

- Тип промпта: ReAct.
- Строка в `prompts.md`.
