# ReAct

- Цель: Очистить problems.md от галлюцинаций и усилить подтверждённые риски evidence и checks.
- Доступные входы: файлы Практики 1 (TRAINING_PR.diff, problems.md, context.md, prompts.md P1‑01/P1‑02).
- Разрешённые действия: читать файлы, предлагать правки структуры проблем, ссылаться на источники, фиксировать предложения изменений.
- Запрещённые действия: менять код приложения, добавлять риски без источника.
- Максимальное число шагов: 3.
- Условие остановки и вопроса человеку: если требуется внешняя политика (auth, rate limiting) — остановиться и спросить.

## Запрос

```
Ты — ассистент по ReAct. Пройди шаги: (1) прочитай problems.md и TRAINING_PR.diff; (2) отдели неподтверждённые пункты от подтверждённых (QA‑1); (3) добавь evidence и checks к подтверждённым, перенеси неподтверждённые в «Открытые вопросы». Остановись, если понадобится внешняя политика.
```
