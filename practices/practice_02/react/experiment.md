# ReAct

- Цель: финально проверить `adr.md` на доказательность и границы.
- Доступные входы: `CASE.md`, `TRAINING_PR.diff`, `adr.md`.
- Разрешённые действия: читать эти файлы, сопоставлять тезисы, предлагать правки ADR.
- Запрещённые действия: web, изменение кода, approve/merge, использование иных источников.
- Максимальное число шагов: 5.
- Остановка: все тезисы имеют evidence; при нехватке данных — вопрос человеку.

## Запрос

За максимум 5 наблюдаемых действий проверь ADR. Для каждого действия запиши только действие, наблюдение и решение. Исправляй лишь неподтверждённые тезисы.

## Наблюдаемые действия и результаты

| Шаг | Действие | Наблюдение | Решение |
|---|---|---|---|
| 1 | Прочитать diff | Есть прямой prompt, вызов LLM и `comment` | Продолжить |
| 2 | Прочитать правила | Нужны 7 релевантных ограничений | Продолжить |
| 3 | Сверить решение | Pipeline покрывает обязательные правила | Продолжить |
| 4 | Сверить альтернативы и риск | Очередь не объявлена обязательной; риск проверяем | Продолжить |
| 5 | Проверить границы и evidence | `SCOPE-1` и `OBS-1` явно указаны | Остановиться |
