# Практика 2. Дорабатываем SDLC-артефакты с помощью шести техник

**Формат:** те же команды, 90 минут.

**Вход:** заполненные файлы Практики 1.

**Результат:** шесть воспроизводимых экспериментов и конкретные изменения в SDLC-артефактах.

## Что вы сдаёте

| Файл | Содержание |
|---|---|
| [`prompts.md`](prompts.md) | единая таблица всех экспериментов и ссылок на изменения |
| [`few_shot/experiment.md`](few_shot/experiment.md) | хороший и плохой примеры результата |
| [`rctf/experiment.md`](rctf/experiment.md) | Role, Context, Task, Format |
| [`chain_of_verification/experiment.md`](chain_of_verification/experiment.md) | вопросы проверки, evidence и исправленный результат |
| [`tree_of_thoughts/experiment.md`](tree_of_thoughts/experiment.md) | три внешне описанные альтернативы и критерии выбора |
| [`rag/experiment.md`](rag/experiment.md) | ограниченный набор источников и ссылки на доказательства |
| [`react/experiment.md`](react/experiment.md) | разрешённые действия, наблюдения, лимит и остановка |

Скрытую Chain of Thought сохранять и сдавать не нужно. Оцениваются наблюдаемые альтернативы, вопросы проверки, источники, действия и изменения файлов.

## Маршрут занятия

### 0–10 минут. Выберите слабый артефакт

Откройте файлы Практики 1 и выберите один артефакт, которому доверяете меньше всего. Зафиксируйте его и проблему в `prompts.md`.

### 10–46 минут. Шесть экспериментов

На каждый эксперимент — 6 минут:

1. заполните вход и запрос в соответствующем `experiment.md`;
2. выполните запрос в OpenCode или другом LLM-интерфейсе;
3. сохраните краткий результат;
4. измените реальный файл Практики 1;
5. укажите проверку и то, что отклонили.

### 46–65 минут. Сведите изменения

Обновите `prompts.md`. В каждой строке должна быть ссылка на конкретный файл и раздел Практики 1, а не фраза «стало лучше».

### 65–80 минут. Независимая проверка

Другая команда получает изменённые артефакты и находит:

- одну двусмысленность;
- одно непроверяемое требование;
- один пропущенный риск или источник.

### 80–90 минут. Исправьте артефакты

Исправьте текст и добавьте evidence. Устное объяснение не заменяет изменение файла.

## Домашняя работа

1. Завершите все шесть `experiment.md`.
2. Обновите связанные файлы Практики 1.
3. Проверьте ссылки из `prompts.md` и замечания независимой команды.
4. Из корня репозитория запустите:

   ```bash
   make step2
   ```

## Оценка — 10 баллов

| Что проверяем | Баллы |
|---|---:|
| Обязательная структура и `make step2` | 1 |
| Шесть заполненных экспериментов и единый журнал | 2 |
| Техники применены по назначению и дают различимые результаты | 3 |
| Есть ссылки на конкретные изменения файлов Практики 1 | 2 |
| Проверки, evidence и исправления после независимого ревью | 2 |
