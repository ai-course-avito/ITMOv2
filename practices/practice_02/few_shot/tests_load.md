## Результат конвертации в Gherkin

```gherkin
@API-1
Scenario: Проверка 413 при превышении лимита длины
  Given шаговая длина diff: 19990, 20000, 20010 символов
  When отправляем POST "/api/reviews" по 20 запросов на каждую длину
  Then при 20010/20001 получаем 413 в 100% случаев; при 19990/20000 получаем 200

@REL-1
Scenario: Смешанная нагрузка с таймаутами LLM
  Given профиль нагрузки 3 RPS в течение 10 минут
  And инжект таймаута LLM в 10% запросов (10с)
  When отправляем валидные тела
  Then P95 ≤ 1.5 с и 5xx ≤ 0.5%

@OUT-1
Scenario: Валидация схемы под нагрузкой
  Given профиль нагрузки 2 RPS в течение 5 минут
  And 50% тел невалидны (отсутствует diff/не строка)
  When отправляем POST "/api/reviews"
  Then доля 422 = 50% ± 2%; p95 для 422 ≤ 200 мс; 5xx = 0
```
