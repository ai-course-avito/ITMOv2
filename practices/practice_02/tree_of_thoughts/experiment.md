# Tree of Thoughts

- Решение, для которого нужны альтернативы: Стратегия обращения с неподтверждёнными пунктами из problems.md (удалять, помечать как вопросы, разделять файл).
- Критерии выбора: Проверяемость (QA‑1), прозрачность для команды, минимальность изменений, пригодность для ревью.

## Запрос

```
Нужны три альтернативы обращения с неподтверждёнными пунктами problems.md: (A) удалять; (B) переносить в «Открытые вопросы» с проверками; (C) разделять на отдельный файл вопросов. Опиши плюсы/минусы по критериям: проверяемость (QA‑1), прозрачность, минимальность, пригодность для ревью.
```

## Внешне описанные альтернативы

| Альтернатива | Плюсы | Минусы | Оценка по критериям |
|---|---|---|---|
| A: Удалять неподтверждённые | Жёстко следует QA‑1; список чистый | Потеря потенциальных гипотез | Проверяемость: высокая; Прозрачность: средняя; Минимальность: высокая; Пригодность: средняя |
| B: Переносить в «Открытые вопросы» | Сохраняет гипотезы, отделяет от рисков | Требует дисциплины в проверках | Проверяемость: высокая; Прозрачность: высокая; Минимальность: средняя; Пригодность: высокая |
| C: Отдельный файл вопросов | Максимальная прозрачность | Доп. артефакт, усложнение навигации | Проверяемость: высокая; Прозрачность: высокая; Минимальность: низкая; Пригодность: средняя |

## Выбор

- Выбранная альтернатива: B — переносить неподтверждённые пункты в «open_questions» внутри P1‑02 Result JSON, с предложенными проверками.
- Почему: минимально меняет структуру, сохраняет гипотезы, повышает прозрачность.
- Как проверим: визуальный аудит проблем и вопросов; соответствие QA‑1; наличие checks для вопросов.

## Что изменили в исходном артефакте

- Файл и раздел: practices/practice_01/prompts.md — «P1‑02 Result (OUT‑1)» JSON.
- Предложение изменения: перенести спорные риски в «open_questions» внутри JSON P1‑02 Result и оставить подтверждённые в `risks`.
- Что отклонили: вариант с удалением спорных пунктов без фиксации вопросов.
- Примечание: исходный файл Практики 1 не изменяли; изменение зафиксировано здесь.
