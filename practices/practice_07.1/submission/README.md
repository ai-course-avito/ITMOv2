# ИТМО 7.1 · Ревью pull requests

[Экспорт n8n](review-pr.json) · [Исходник Workflow SDK](review-pr.workflow.js) · [Тестовый PR №1](https://github.com/vlklk/itmo-n8n-lab/pull/1)

- При открытии PR и команде `/make_ai_review` выбирается `qwen3.5:9b`. Команда `/make_other_ai_review` выбирает `qwen2.5-coder:3b`. Команды принимаются от владельца, участника организации или collaborator.
- Патчи приходят из GitHub REST API файлов PR. Ревью ограничено первой страницей (до 100 файлов) и 18 000 знаков. При пропуске файлов или усечении модели передаётся предупреждение.
- После публикации комментария Data Table `itmo-pr-reviews` сохраняет номер PR в `prId`, модель и составной ключ из репозитория, номера PR и варианта модели. Повтор основной команды останавливается на проверке существующей строки.

- Бонус с комментариями к каждому блоку diff требует отдельной доработки.

Для переноса подключите GitHub credential к триггеру, HTTP Request и узлу публикации комментария. Замените учебный репозиторий в триггере, фильтре события и запросах, выберите свою Data Table и адрес Ollama. В тестовом экземпляре GitHub доставляет события через HTTPS-шлюз с двумя разрешёнными webhook-маршрутами. GitHub Trigger проверяет подпись. Ревьюверу потребуется доступ к тестовому репозиторию для открытия ссылки.
