## Дополнительный локальный прогон 8k — 25.09.2026

Это дополнительная проверка на MacBook Air M2 с 8 GB RAM, а не замена обязательного 64k-этапа методички. Существующий контрольный запуск 64k подтверждает реальный `read`; отдельный финальный ответ в его файлах не подтверждён. По предыдущим сообщениям пользователя, полное ожидание 64k составляло около 10 минут, а последующие попытки не укладывались в лимиты рабочего окружения. Эти сведения не являются новым измерением настоящего прогона.

Создан отдельный `lab/Modelfile.agent.local`: `FROM qwen3.5:4b`, `num_ctx=8192`, `temperature=0.2`, без дополнительного SYSTEM. Создан профиль `itmo-agent-local` (ID `cbca2d1ed2b2`). Исходные `Modelfile.agent`, модель `itmo-agent`, все файлы `lab/demo` и прежние непустые результаты сохранены; проверены контрольные суммы файлов и вывод `ollama show itmo-agent --modelfile` до/после.

Фактические ресурсы: `ollama ps` — контекст **8192**, размер **4.0 GB**, размещение **21%/79% CPU/GPU**. Снимки: `lab/results/local8k-resources.json`, `local8k-ollama-ps.txt`. Это снимок состояния, а не замер пикового потребления памяти.

Конфигурация `lab/opencode.local.json` передаётся через `OPENCODE_CONFIG_CONTENT`, чтобы не менять `demo/opencode.json`. Итоговая конфигурация проверена: основная и малая модели — `ollama/itmo-agent-local`, endpoint `http://localhost:11434/v1`, разрешён только провайдер `ollama`, MCP и плагины отсутствуют, публикация отключена. `local-guide` сохранил исходный prompt, лимит 8 шагов и разрешения только `read`, `glob`, `grep`. ### Запуски и сохранность результатов

При начале работы существовал только пустой `question1.jsonl`; он был удалён после проверки размера 0 B. Файлы 2–5 отсутствовали. Рабочие запуски используют абсолютный путь к `demo`.

Первая модельная попытка вопроса 1 выполнила `glob`, но несколько минут не давала финального ответа; она прервана, её **непустой `question1.jsonl` не перезаписан**. Повтор сохранён как `question1.retry.jsonl`. Для дальнейших запусков задано явное `--title`, чтобы не требовалась дополнительная генерация названия сессии. После этого первый вопрос завершился за 25.66 с; причинную связь по единственному повтору не утверждаем.

Вопрос 5 первоначально завершился с exit code 0 и `stop`, но без события `text`. Экспорт той же сессии подтвердил отсутствие финального текста; внутренние рассуждения не подставлялись вместо ответа. Таким образом, сохранены все пять `questionN.jsonl` и два дополнительных файла повторов.

Каждый запуск — новый `opencode run`, без `--continue` и `--session`. Вход — точный вопрос из `QUESTIONS.md`, без отчёта, эталонов и истории рабочего чата. Завершённые ответы имеют пять разных sessionID; вызовы инструментов обращались только к `demo`. Выбранные завершённые JSONL содержат текст ответа и события инструментов, без событий `reasoning`.

Команда для воспроизведения из `lab/` (выходной путь должен быть новым; `set -C` защищает существующий файл):

```bash
ollama create itmo-agent-local -f Modelfile.agent.local
set -C
OPENCODE_CONFIG_CONTENT="$(cat opencode.local.json)" \
  opencode run --pure --dir "$PWD/demo" --agent local-guide \
  --model ollama/itmo-agent-local --format json \
  --title "Practice 3 question N 8k" "ТОЧНЫЙ ВОПРОС ИЗ QUESTIONS.md" \
  > results/questionN.new.jsonl

```

Для каждого завершённого запуска сохранён `*.run.json` с кодом выхода и длительностью, а также отдельный stderr. Предупреждение `Error starting FSEvents stream` присутствовало, но завершённые сессии вернули 0, выполнили инструменты и сохранили текст. Длительности включают запуск процесса и работу агента; это не TTFT и не tokens/s, холодный старт отдельно не измерялся.
