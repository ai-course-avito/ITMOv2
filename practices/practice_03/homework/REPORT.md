## Воспроизведение
Действовать из каталога `homework`.

1. Проверить наличие профиля модели:
   - Если профиля нет, создать: `ollama create itmo-agent-local -f Modelfile.local`.
2. Стадии запуска: `python3 run_local.py --stage all` или по отдельности `--stage questions`, `--stage bench`, `--stage smoke`.
3. Запускатель сохранит новые результаты в `results/<timestamp>`: `summary.json`, `model.json`, `*.jsonl`, `*.run.json`, `*.requests.json` и `*.ollama-ps.json`. `verification.json` текущей сдачи — итоговая проверка после серии; запускатель автоматически её не создаёт.

Для воспроизведения нужны Python 3.10+, OpenCode и запущенный Ollama. Используется стандартная библиотека Python. При отсутствии базовых весов сначала выполните `ollama pull qwen3.5:4b`; проверьте версию модели и digest по этому отчёту. Существующий профиль не пересоздавайте.

В комплекте сдачи оставлены финальные ответы и события инструментов (`*.jsonl`), времена всех 18 запусков (`summary.json`), сведения о модели (`model.json`) и итоговая проверка (`verification.json`). Повторяющиеся конфигурации каждого запуска, промежуточные снимки сервера, журналы запросов и stderr удалены; основные конфигурации A/B сохранены. Запускатель при повторе создаёт такие диагностические файлы заново.
