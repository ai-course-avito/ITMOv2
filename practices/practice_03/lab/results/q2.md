    ```python
    if not name.strip():  # Если после удаления пробелов строка пустая
        raise ValueError("empty name") # Вызывается исключение
    ```
*   **`test_service.py` (строки 13–15):**
    ```python
    def test_empty(self):
        with self.assertRaises(ValueError):  # Ожидаемое исключение

    ```
