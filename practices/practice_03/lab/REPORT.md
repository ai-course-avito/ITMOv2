# REPORT — Практика 3 (локальные модели)

## Железо
- ОС: Manjaro Linux (rolling), kernel 6.12 x86_64
- CPU: AMD Ryzen 5 7640HS (6C/12T)
- GPU: iGPU AMD (amdgpu), без дискретной NVIDIA/ROCm
- RAM: 14 GiB (доступно во время прогонов ~2–4 GiB)

## Версии
- Ollama: 0.33.3 (service active)
- OpenCode: 1.18.35
- Базовая модель: qwen3.5:4b

## Локальная модель и квантизация
- Имя: itmo-agent (Ollama)
- База: qwen3.5:4b
- Квантизация: Q4_K_M (ollama show itmo-agent)
- Параметры в Modelfile: num_ctx=2048, num_predict=256, temperature=0.7

## Настройки OpenCode (ключевые)
- Провайдер: local-ollama (baseURL: http://localhost:11434/v1, timeout: 600000)
- Модель: local-ollama/itmo-agent
- Лимиты для снижения RAM:
  - context: 2048
  - output: 768 (для финального прогона вопросов; ранее снижали до 512 и поднимали обратно)

## Обоснование выбора модели
- 4B (qwen3.5:4b, Q4_K_M) — компромисс качества на CPU без дискретного GPU.
- Небольшие лимиты контекста/вывода позволяют избежать OOM на 14 GiB RAM.
- Для быстрых служебных шагов предусмотрена более лёгкая модель gemma3:270m.

## Что получилось
- Связка OpenCode ↔ Ollama работает локально через local-ollama.
- Модель собирается через Modelfile и доступна в `ollama list`.
- Тесты `lab/demo` проходят (python3 -m unittest -v; OK, 3 теста).
- Вопросы запущены в отдельных read-only сессиях без утечки эталонов.

## Что не получилось / Ограничения
- При жёстких лимитах (context=1024, output=512) ответы обрезались; часть пустых.
- Read-only агент строг к инструментам; при ошибках tool-вызовов ответы могут быть пустыми.
- Даже при context=2048/output=768 модель дала 1–2 слабых ответа.

## Скорость и стабильность
- На CPU ответы приходят стабильно после снижения лимитов; без OOM.
- Скорость удовлетворительная для коротких ответов (точных токенов/сек не мерили в отчёте).

## Примеры
- Проверка связки: короткий запрос «Привет, ответь одним предложением» — ответ от local-ollama/itmo-agent пришёл.
- Тесты: см. `.eval/test-output.txt` (OK).

## Выводы
- На CPU без дискретной GPU 4B-модель в Q4_K_M работоспособна, но требует строгих лимитов.
- Для задач с цитированием строк лучше слегка увеличить лимиты вывода либо использовать более лаконичные формулировки вопросов.
