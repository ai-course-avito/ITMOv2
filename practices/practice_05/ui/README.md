# UI для Subscription Service

Простой веб‑интерфейс для работы с сервисом подписки:
- Добавление подписчика (email + имя)
- Просмотр списка подписчиков
- Удаление подписчика

## Структура

- index.html — страница UI
- script.js — логика работы с API
- styles.css — минимальные стили

UI отдается статикой встроенным сервером без внешних зависимостей и работает с ним на одном origin.

## Как запустить

1. Запустите сервис и UI одной командой из корня репозитория:
   ```bash
   make -C practices/practice_05 run
   ```
2. Откройте в браузере:
   - http://localhost:8000/

Проверка API (smoke):
- http://localhost:8000/health → {"status":"ok"}
- http://localhost:8000/version → {"version":"0.1.0"}

## Примечания
- Данные сохраняются в файл JSON: `practices/practice_05/data/subscribers.json`.
- Кнопка удаления подтверждается диалогом.
- UI использует API:
  - POST /subscribe {email, name?}
  - GET /subscribers
  - DELETE /subscribers/{email}

## Поиск по нику (username)

- Поле поиска расположено над таблицей подписчиков, метка: «Поиск по нику (username)».
- Поиск выполняется по мере ввода (debounce ~300 мс) при длине запроса ≥ 2 символов, максимум 100 символов.
- Предыдущие незавершённые запросы отменяются.
- Пустая строка/короткий запрос (<2) — фильтр снимается, отображается полный список.
- Кнопка «×» очищает поле, клавиша Esc при фокусе на поле также очищает.
- Счётчик рядом с полем показывает общее число результатов и количество на текущей странице.
- Пагинация результатов: кнопки «Предыдущая/Следующая», указатель текущей страницы.
