# Data Model: Веб-страница ревью диффа

## Исход запроса (`Outcome`)

Результат `interpretResponse` / `review()`:

| Поле | Тип | Когда |
|---|---|---|
| `kind` | `ok` \| `rejected` \| `model_error` \| `request_error` \| `network` | всегда |
| `code` | строка \| null | `rejected`, `model_error`, `request_error` |
| `review` | строка | только `ok` |
| `stats` | `{files, added, removed}` | `ok`, `model_error` |
| `details` | строка \| null | `message` сервера и HTTP-код — для «подробнее» |

Соответствие телу ответа (контракт п.3–5, 10):

| `status` в теле | `kind` |
|---|---|
| `ok` | `ok` |
| `rejected` | `rejected` |
| `error` | `model_error` |
| `request_error` | `request_error` |
| не JSON / нет ответа / тайм-аут / неизвестный `status` | `network` |

## Состояние страницы (`ViewState`)

| Состояние | Кнопка | Индикатор | Ревью | Статистика | Сообщение |
|---|---|---|---|---|---|
| пусто | недоступна | нет | нет | нет | нет |
| ввод (готов) | доступна | нет | нет | нет | нет |
| загрузка | недоступна | да | нет | нет | нет |
| успех | доступна | нет | да | да | нет |
| отказ (`rejected`, `request_too_large`) | доступна | нет | нет | нет | текст отказа |
| ошибка модели | доступна | нет | нет | да | текст ошибки модели |
| ошибка сети/сервера (`network`, прочие `request_error`) | доступна | нет | нет | нет | текст + «повторите» |

Переходы: пусто ↔ ввод (по `canSubmit`); ввод → загрузка (нажатие);
загрузка → успех/отказ/ошибка; любое сообщение → ввод при правке поля
(FR-011); повторное нажатие из любого итогового состояния → загрузка
(FR-010).

## Тексты для пользователя (`USER_TEXT`)

| Ключ | Текст |
|---|---|
| `empty_diff` | Дифф пустой — вставьте текст изменений. |
| `diff_too_large`, `request_too_large` | Дифф слишком большой: допустимо до 8192 байт. Сократите его и повторите. |
| `model_timeout` | Модель не ответила вовремя. Статистика посчитана, ревью можно запросить ещё раз. |
| `model_unavailable` | Модель сейчас недоступна. Статистика посчитана, попробуйте позже. |
| `model_http_error`, `model_bad_response` | Модель вернула ошибку. Статистика посчитана, попробуйте ещё раз. |
| `network` (и прочие `request_error`) | Не удалось получить ответ сервиса. Проверьте, что он запущен, и повторите. |
