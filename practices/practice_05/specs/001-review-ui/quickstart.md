# Quickstart: Веб-страница ревью диффа

Из `practices/practice_05`.

## Автоматическая проверка

```
sh scripts/check.sh            # включает node --test 'web/*.test.js'
node --test 'web/*.test.js'    # только тесты страницы
```

## Сквозная проверка в браузере (после реализации обеих команд)

```
python3 -m app.server --fake-model
```

Открыть `http://127.0.0.1:8055/`:

| Шаг | Ожидание |
|---|---|
| страница открыта, поле пустое | кнопка «Ревью» недоступна |
| вставить `--- a\n+++ b\n+x` и нажать «Ревью» | индикатор, затем текст демо-ревью и статистика 1 / +1 / −0 |
| вставить > 8192 байт | «Дифф слишком большой…», без статистики |
| остановить сервер, нажать «Ревью» | «Не удалось получить ответ сервиса…» |
| запустить без `--fake-model` при остановленной Ollama | «Модель сейчас недоступна…» + статистика |
