# event-admin-ui Specification

## Purpose
Управление событиями карты из админ-панели клиента без прямых запросов к API.

## Requirements

### Requirement: Edit event from admin panel
Админ-панель SHALL позволять пользователю с ролью `ADMIN` изменить `name`, `description`, `link` и планету события. Форма MUST открываться с текущими значениями события.

#### Scenario: Успешное изменение
- **WHEN** администратор меняет название события и сохраняет форму
- **THEN** карточка планеты показывает новое название без перезагрузки страницы

#### Scenario: Перенос на другую планету
- **WHEN** администратор выбирает другую планету и сохраняет форму
- **THEN** событие пропадает из хроники старой планеты и появляется в хронике новой

#### Scenario: Ошибка сервера
- **WHEN** сервер отвечает 400 или 404
- **THEN** форма остаётся открытой и показывает сообщение об ошибке

#### Scenario: Пользователь без роли ADMIN
- **WHEN** карточку планеты открывает пользователь без роли `ADMIN`
- **THEN** кнопка редактирования события не отображается
