# Proposal

## Why

Сервер умеет редактировать события (`PUT /events/:id`, spec `events`), но в админ-панели есть только создание и удаление события. README обещает редактирование событий в админ-панели, а администратору по-прежнему приходится удалять и создавать событие заново.

## What Changes

- Кнопка редактирования у события в карточке планеты для пользователя с ролью `ADMIN`.
- Форма редактирования с полями `name`, `description`, `link` и выбором планеты, заполненная текущими значениями.
- Thunk `updateEvent` в `planetSlices` отправляет JSON на `PUT /events/:id` и после успеха перезагружает планеты.

Не входит в изменение: замена снимков события, изменения сервера.

## Capabilities

### New Capabilities
- `event-admin-ui`: управление событиями в админ-панели клиента.

### Modified Capabilities

## Impact

- `client/lib/slices/planetSlices.ts`, `client/components/admin/`
