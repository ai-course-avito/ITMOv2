# Рефлексия ДЗ 5

## Зафиксированные решения

- Пользователь выбрал AI-помощника ревью PR и разрешил двум независимым агентам
  подготовить спецификации UI и логики.
- Перед кодом обсуждались непустой список проверок, обязательная привязка риска
  к строке diff, единый формат ошибок и различие ожидания модели/UI.
- После рекомендации использовать формулировку «Возможные риски» пользователь
  ответил «Тогда одобряю». Согласованные версии сохранены до реализации.
- Истинность вывода модели оставлена на проверку человека: совпадение цитаты
  подтверждает только присутствие строки в diff.

## Личная оценка студентки

Пока не получена. Этот раздел заполняется после ручного демо по сообщениям
пользователя, без выдуманных впечатлений или оценки от имени студентки.

Для завершения достаточно ответить своими словами:
1. Что помогло при согласовании UI и логики?
2. Какое решение показалось самым важным или спорным?
3. Что после демо хотелось бы улучшить?
