# Отчёт по практике 5: фича «3D-машинки» через OpenSpec

В проекте «Гонки» (FastAPI + Vue 3) одна фича доведена по циклу из лекции:
**explore → propose → review → apply → проверки → sync → archive**.

---

## 1. Фича

- **Было:** машинки рисовались плоскими прямоугольниками на Canvas 2D, объём не виден.
- **Стало:** трасса и обе машинки — 3D-сцена на Three.js. Камера неподвижная, под углом 52°, видно всё поле. Машинки собраны из простых форм (корпус, кабина, колёса, фары), три модели различаются пропорциями, цвет берётся из выбранного. На поворотах объём и тень хорошо видны.
- **Не менялось:** физика, управление, подсчёт круга, экраны отсчёта и победы, бэкенд. Изменён только фронтенд: новый `scene3d.js`, правки в `App.vue`, зависимость `three` в `package.json`.

---

## 2. Как шёл цикл OpenSpec

| Этап | Что сделано | Результат |
|---|---|---|
| **Explore** | Обсудили варианты: псевдо-3D из слоёв, настоящее 3D, спрайты под каждый угол. Выбрано настоящее 3D из простых форм, камера на всё поле | Код не менялся, решения зафиксированы |
| **Propose** | Создано изменение `car-3d-rendering` | `proposal.md`, `specs/car-rendering/spec.md` (8 требований, 12 сценариев), `design.md`, `tasks.md` (15 задач) |
| **Review** | План сверен с запросом до написания кода | Найдены два дополнения к запросу, приняты; две неточности исправлены (см. раздел 4) |
| **Apply** | Выполнены все задачи | `tasks.md`: 15/15 `[x]` |
| **Проверки** | См. раздел 3 | Всё прошло |
| **Sync** | Спека изменения стала основной | Создан `openspec/specs/car-rendering/spec.md` |
| **Archive** | Изменение перенесено в историю | `openspec/changes/archive/2026-10-21-car-3d-rendering/`, активных изменений нет |

## 3. Проверки

Вывод из лекции: галочка в `tasks.md` не равна выполненному требованию, поэтому проверялось поведение.

| Проверка | Результат |
|---|---|
| `bash scripts/check.sh` (ruff, формат, pytest) | PASS, 11 тестов бэкенда |
| `npm run build` | Проходит; бандл вырос до 617 КБ из-за `three` |
| Физика не изменена | Функции `updatePhysics`, `keepInsideTrack`, `checkLap`, `declareWinner`, `initCars` совпадают с прежними |
| Полный круг двумя машинками | Старая 2D и новая 3D версии дают одинаковый итог: 340 кадров, победил игрок 1 |
| Упор в бордюры, задний ход | Работают как раньше |
| Три модели и цвета | Модели различимы по силуэту, цвет совпадает с выбранным |
| Пять гонок подряд | Без ошибок в консоли, частота кадров не падает |
| Нет WebGL | Вместо пустого экрана — сообщение и кнопка «Назад к выбору» |

**Что не проверено:** у фронтенда нет автотестов, он проверялся скриптом в браузере со скриншотами. Плавность замерена на программном рендере (6–8 кадров/с), на реальной видеокарте она выше.

---

## 4. Где потребовалось моё решение

- Выбрала подход: настоящее 3D вместо псевдо-объёма и неподвижную камеру на всё поле.
- Когда план был создан раньше моего разрешения (на этапе обсуждения), отклонила его. План удалён и создан заново через `propose` по моей команде.
- На review нашлись неточности в плане: перепутаны цвета бордюров, а число задач указано 13 вместо 15. Исправлено до начала проверок.
- Решила не вносить правок в план после review (`/opsx:update` не понадобился) и закрыть фичу.
