# Выбор аэропорта по городу

## Как пользоваться

На странице поиска введите город в поле «Откуда» и выберите конкретный аэропорт. Повторите в поле «Куда», задайте даты и фильтры и нажмите «Найти билеты». В варианте и в подтверждённом поле видны город и аэропорт. Стрелки вверх и вниз перемещают выделение по списку, `Enter` выбирает вариант, `Escape` закрывает список.

Справочник содержит 45 европейских столиц и три дополнительных города из первой версии (Санкт-Петербург, Казань, Сочи). Всего доступны 48 городов и 58 аэропортов:

Поиск подсказок учитывает только начало названия города, без учёта регистра и пробелов по краям. Другие города, название аэропорта отдельно и свободно введённый IATA-код выбрать нельзя. Если совпадений нет, форма показывает «Аэропорты не найдены». Для Никосии и Рейкьявика показаны обслуживающие их аэропорты в соседних городах — Ларнака и Кефлавик. Андорра-ла-Велья, Вадуц, Монако, Сан-Марино и Ватикан не включены: у них нет собственного аэропорта для выбора.

## Поведение формы

Оба поля изначально пустые. Ввод и выбор аэропорта не обращаются к API и не меняют прежний результат. Любое изменение текста после выбора снимает подтверждение только у изменённого поля. Поиск требует двух подтверждённых разных аэропортов; разные аэропорты Москвы допустимы.

При нажатии кнопки прежний результат и сравнение цен очищаются. Ошибка выбора показывается у соответствующего поля, а ошибочная дата, совпадающие аэропорты или ошибка сервиса — общим сообщением. При успешной проверке выполняется один запрос в существующий endpoint с IATA-кодами, датами и прежними фильтрами. При ошибке сервиса выбранные аэропорты остаются в форме для повтора.

Справочник локален во фронтенде; отдельного API подсказок нет. Серверный контракт поиска и его правила в этом UI-изменении не меняются. Наличие аэропорта в справочнике не гарантирует доступность рейсов на выбранную дату. Коды московских аэропортов сверены с [материалом IATA](https://www.iata.org/contentassets/c33c192da39a42fcac34cb5ac81fd2ea/ads_ab_2022_02-joint-iata-atpco-notification-ccd-list.pdf); состав первой версии задан [общим контрактом](../../../../specs/001-city-airport-selection/contract.md).
