# Spec Delta

## Purpose

Работа с каталогом товаров и остатками на складах из интерфейса: список товаров с созданием и правкой, добавление товаров на выбранный склад с количеством.

## ADDED Requirements

### Requirement: Список товаров
Интерфейс SHALL показывать каталог со всеми товарами (SKU, название, описание, суммарный остаток по складам) и позволять создавать, изменять и удалять товары. Ошибки API (дубликат SKU, удаление товара с остатком) SHALL показываться сообщением, данные в списке остаются прежними.

#### Scenario: Создание товара
- **WHEN** пользователь заполняет SKU и название и сохраняет
- **THEN** товар появляется в списке

#### Scenario: Дубликат SKU
- **WHEN** пользователь создаёт товар с занятым SKU
- **THEN** показывается сообщение «SKU уже занят» и список не меняется

#### Scenario: Удаление товара с остатком
- **WHEN** пользователь удаляет товар, который лежит на складе
- **THEN** показывается сообщение об отказе и товар остаётся

### Requirement: Товары на складе
Панель свойств склада SHALL показывать его остатки (товар, всего, в резерве, доступно) и позволять добавить товар из каталога с количеством, изменить количество строки и убрать строку. Отказы API (количество ниже резерва, строка в резерве) SHALL показываться сообщением.

#### Scenario: Добавление товара на склад
- **WHEN** пользователь выбирает товар, вводит 10 и нажимает «Добавить»
- **THEN** в остатках склада появляется строка с количеством 10

#### Scenario: Пополнение
- **WHEN** пользователь добавляет тот же товар ещё раз с количеством 5
- **THEN** количество строки увеличивается на 5

#### Scenario: Количество ниже резерва
- **WHEN** пользователь задаёт количество меньше резерва
- **THEN** показывается сообщение «ниже резерва» и значение не меняется

### Requirement: Остатки на карте
Склад на карте SHALL показывать суммарное количество товаров, а при ненулевом резерве ещё и резерв, обновляя их без перезагрузки страницы.

#### Scenario: Остаток обновился
- **WHEN** на склад добавили товар
- **THEN** значение на бейдже склада на карте меняется в течение нескольких секунд
