# Proposal

## Why

У Argon Logistics есть только HTTP API. Чтобы собирать сеть складов и ПВЗ, наполнять склады, делать заказы и видеть, как едут грузовики, нужен веб-интерфейс. Бэкенд при этом не умеет двух вещей, без которых интерфейс невозможен: хранить положение объектов на карте и сам «ездить» (сейчас отгрузка и доставка вызываются руками). Нужно и поднимать всё одной командой.

## What Changes

- Новый фронтенд на Next.js (React, TypeScript) в стиле Material Design 3, каталог `web/`.
- **Карта-редактор:** панель «Строения» (перетаскиваешь склад или ПВЗ на карту), перемещение объектов, связи между ними с временем в минутах.
- **Каталог и остатки:** список товаров (CRUD), товары на складах с количеством.
- **Планшет заказа:** отдельная панель-планшет: каталог, корзина, выбор ПВЗ, предпросмотр маршрута, оформление, мои заказы.
- **Живая логистика:** список активных заказов со статусами и степпером, на карте анимированные грузовики, едущие от объекта к объекту.
- **Бэкенд:** координаты складов и ПВЗ на карте, снимок всей сети одним запросом, фоновая симуляция (авто-отгрузка и авто-доставка с ускорением времени), эндпоинт с параметрами симуляции.
- **Развёртывание:** `docker compose up` поднимает API и web; web проксирует `/api` на бэкенд.

**Вне изменения:** авторизация (клиент по-прежнему определяется гостевым `X-User-Id`), мобильная вёрстка карты-редактора (планшет и карта рассчитаны на экран от 900 px), реальные карты/геокоординаты, WebSocket/SSE (используется опрос), e2e-тесты браузера, изменение логики планирования.

## Capabilities

### New Capabilities
- `network-map`: позиции складов и ПВЗ на карте и снимок всей сети одним запросом.
- `logistics-simulation`: автоматическая отгрузка и доставка с ускоренным временем.
- `map-editor`: построение сети на карте (строения, перемещение, связи со временем).
- `catalog-and-stock-ui`: товары и остатки на складах в интерфейсе.
- `order-tablet`: оформление заказа на панели-планшете.
- `live-logistics`: активные заказы, статусы и анимация грузовиков.
- `deployment`: запуск всей системы через Docker Compose.

### Modified Capabilities

(нет: capability из change `argon-logistics-core` ещё не заархивированы, поэтому расширения оформлены как новые capability и не меняют их требований)

## Impact

- Backend: поля `mapX`/`mapY` у складов и ПВЗ (схема БД меняется; `EnsureCreated` не мигрирует, старый `argon.db` нужно удалить), новые эндпоинты `/api/network`, `/api/simulation`, `PUT .../position`, фоновый сервис.
- Новый код: `web/` (Next.js), `Dockerfile` у API и web, `docker-compose.yml`.
- Зависимости web: Next.js, React, SWR, шрифты Roboto и Material Symbols (через npm, без CDN).
