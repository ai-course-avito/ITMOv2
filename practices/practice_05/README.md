# ДЗ 5: две команды — одна фича

Ветка `practice_05` создана от актуального `origin/main` (`0c8a9c1`).
Источник задания — [prenetation.pdf](prenetation.pdf), страница 16.
Продукт: AI-помощник ревью PR, выбранный пользователем ранее.

## Условие и критерии

| Критерий | Баллы | Что готовим |
|---|---:|---|
| Другой SDD-фреймворк, применение и сравнение с OpenSpec | 2 | GitHub Spec Kit 1.2.3, реальные шаблоны/команды, сравнение |
| Две спецификации UI и логики, согласованные до кода | 2 | Независимые drafts, общий контракт, решение пользователя, версии до/после |
| Работающие UI и логика, сквозные проверки | 5 | Реализация после согласования; успех, ошибка и граница через UI |
| Рефлексия: что согласовали и чему научились | 1 | Личная оценка пользователя после работы |

Сдача: спецификации до/после, общий контракт, код, проверки, короткое демо.

Два агента работают в отдельных контекстах по разрешению пользователя.
Команда UI владеет `project/specs/001-review-ui/`, команда логики —
`project/specs/002-review-logic/`. Первые версии создаются без чтения работы
другой команды. Координатор затем сохраняет snapshots и готовит контракт.
Факт принятия человеком нельзя заменять решением агента.
