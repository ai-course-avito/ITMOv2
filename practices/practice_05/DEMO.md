# Короткое демо для сдачи ДЗ 5

## Запуск

Из корня ITMOv2:

```bash
make -C practices/practice_05/project run
```

Открыть http://127.0.0.1:8000. Режим по умолчанию — demo, реальная модель
не вызывается. Инструкции установки и live-конфигурации — в project/README.md.

## Сценарий на 2–3 минуты

1. Показать ветку practice_05 и страницу 16 prenetation.pdf — другое SDD-средство,
   две спецификации, контракт до кода, UI+логика и сквозной сценарий.
2. Открыть RECONCILIATION.md: объяснить два отличия исходных спецификаций
   (checks и обязательная строка риска) и принятое решение из CONTRACT.md.
   Показать evidence/before, evidence/after и specs-before-after.diff.
3. Показать Spec Kit .specify/memory/constitution.md, обе specs и plan/tasks.
   Commit 5301bc5 фиксирует согласованные документы до прикладного кода.
4. Вставить весь inputs/TRAINING_PR.diff и нажать «Проверить diff».
   Увидеть summary, три возможных риска с цитатами, checks и явный маркер ДЕМО.
   Пояснить, что это правила воспроизводимой демонстрации, а live имеет отдельный adapter.
5. Очистить поле и отправить пустой ввод: увидеть понятную ошибку без потери
   управления. Вставить обычный текст вместо diff: получить отказ backend;
   исправить ввод учебным diff и снова получить результат.
6. Показать evidence/e2e.txt и unit/API отчёт, пример проверки 20000/20001 и
   late-response сценарий. Не выдавать controlled browser errors за сбой реального провайдера.
7. Коротко дать собственную рефлексию по REFLECTION.md.

Остановить сервер Ctrl+C. Локальная демонстрация не создаёт внешних PR/комментариев.
