# User Story 3: редактирование события

Как администратор карты, я хочу изменять название, описание, ссылку и планету события, чтобы исправлять данные без удаления события.

## Условия приёмки

- `PUT /events/:id` принимает только валидные поля события.
- При смене планеты событие удаляется из старой планеты и добавляется в новую.
- Изображения события сохраняются при редактировании.
- Для неизвестного события или планеты API возвращает ошибку 404.
- После изменения `GET /events/:id` возвращает обновлённые данные.

В эту историю не входит замена изображений события.
