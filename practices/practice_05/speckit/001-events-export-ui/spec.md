# Feature Specification: Экспорт событий в JSON

**Feature Branch**: `001-events-export-ui`

**Created**: 2026-10-29

**Status**: Draft

**Input**: User description: "Экспорт событий в JSON: пользователь с ролью ADMIN скачивает все события карты как JSON-файл. Спецификация только для UI."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Скачать все события карты (Priority: P1)

Администратор запускает экспорт из панели управления картой и получает JSON-файл со всеми событиями карты для дальнейшего просмотра или обработки.

**Why this priority**: Это основной пользовательский результат функции.

**Independent Test**: Войти пользователем с ролью `ADMIN`, нажать кнопку экспорта и проверить скачанный файл и состояние интерфейса.

**Acceptance Scenarios**:

1. **Given** администратор находится на экране карты, кнопка экспорта доступна и состояние idle, **When** он нажимает «Экспорт событий», **Then** UI отправляет `GET /api/backend/events/export`, кнопка переходит в loading, повторное нажатие недоступно, а после успешного ответа браузер начинает скачивание файла с именем из `Content-Disposition`.
2. **Given** экспорт завершился успешно и ответ содержит события, **When** файл скачан, **Then** интерфейс возвращается в idle и показывает уведомление «События успешно экспортированы».

### User Story 2 - Понятно обработать отсутствие событий (Priority: P2)

Администратор понимает, что экспорт выполнен, даже если карта пока не содержит событий.

**Why this priority**: Пустая карта является допустимым состоянием и не должна выглядеть как сбой.

**Independent Test**: Выполнить экспорт при пустом наборе событий и проверить файл, уведомление и доступность кнопки.

**Acceptance Scenarios**:

1. **Given** экспорт вернул `200 OK` с `events: []`, **When** администратор запускает экспорт, **Then** скачивается валидный JSON-объект с пустым массивом событий, показывается уведомление «События отсутствуют», а кнопка возвращается в idle.

### User Story 3 - Показать ошибку экспорта (Priority: P2)

Администратор получает объяснение, если экспорт не удался, и может повторить попытку.

**Why this priority**: Ошибка не должна оставлять интерфейс заблокированным или создавать впечатление успешной выгрузки.

**Independent Test**: Смоделировать сетевую ошибку, отказ в доступе и ошибку сервера, затем проверить сообщение и повторный запуск.

**Acceptance Scenarios**:

1. **Given** запрос экспорта завершился ошибкой, **When** ответ обработан, **Then** показывается toast «Ошибка при экспорте событий» с сообщением сервера, если оно доступно, состояние возвращается в idle и повторное нажатие снова доступно.
2. **Given** сессия отсутствует или роль пользователя не `ADMIN`, **When** пользователь открывает экран карты, **Then** кнопка экспорта не отображается; если запрос всё же получил 401 или 403, показывается «Недостаточно прав: войдите как администратор».
3. **Given** сервер вернул статус 413, **When** ответ обработан, **Then** показывается «Слишком много событий для экспорта», состояние возвращается в idle и повторное нажатие снова доступно.

### Edge Cases

- Во время loading повторные нажатия не отправляют дополнительные запросы.
- Если браузер блокирует создание загрузки или файл не удаётся подготовить, показывается «Ошибка при экспорте событий», кнопка возвращается в idle.
- Если ответ не содержит ожидаемый JSON-объект с полями `exportedAt` и `events`, загрузка не начинается и показывается ошибка экспорта.
- При временной сетевой ошибке состояние loading завершается, чтобы администратор мог повторить попытку.
- Экспорт не зависит от текущего поискового запроса, выбранной вкладки или видимого списка: выгружаются все события карты.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: UI MUST показывать управляющий элемент «Экспорт событий» только пользователю с ролью `ADMIN` в панели управления картой рядом с другими админскими действиями.
- **FR-002**: UI MUST при нажатии на элемент экспорта отправлять один `GET`-запрос на `/api/backend/events/export` с cookie сессии и отображать состояние loading до получения результата.
- **FR-003**: UI MUST при успешном ответе `200 OK` с JSON-объектом `{ exportedAt, events }` инициировать скачивание файла с именем из `Content-Disposition`, используя `events.json` без этого заголовка, и показать уведомление об успехе.
- **FR-004**: UI MUST обрабатывать пустой результат как успешный экспорт пустого массива и показывать отдельное уведомление «События отсутствуют».
- **FR-005**: UI MUST показывать «Недостаточно прав: войдите как администратор» для 401/403, «Слишком много событий для экспорта» для 413 и «Ошибка при экспорте событий» для сетевых ошибок, невалидного JSON и 5xx, добавляя `message` сервера, если он есть, и возвращая кнопку в состояние idle.
- **FR-006**: UI MUST сохранять доступность остальных элементов панели и не менять результаты поиска после экспорта.

### Key Entities

- **Событие карты**: запись события, включаемая в экспорт; UI не изменяет её содержимое.
- **Файл экспорта**: JSON-представление `{ exportedAt, events }` для скачивания пользователем; событие без найденной планеты содержит `place: null`.
- **Состояние экспорта**: idle, loading, success, empty или error, определяющее доступность кнопки и уведомления.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Администратор может запустить экспорт не более чем за один клик после открытия панели управления.
- **SC-002**: В 100% успешных запусков браузер получает файл с именем из `Content-Disposition` или `events.json` без заголовка, содержащий валидный JSON-объект `{ exportedAt, events }` без изменения данных.
- **SC-003**: В 100% запусков с `events: []` скачивается валидный JSON-объект с пустым массивом и показывается уведомление «События отсутствуют».
- **SC-004**: После завершения запроса в 100% сценариев кнопка возвращается из loading в idle или остаётся явно доступной для повторной попытки при ошибке.
- **SC-005**: Пользователь без роли `ADMIN` не видит управляющий элемент экспорта в 100% проверенных состояний сессии.
- **SC-006**: Ответ со статусом 413 в 100% случаев показывает «Слишком много событий для экспорта» и не инициирует скачивание файла.
