# Warhammer Map Constitution

## Core Principles

### I. Single Source of Truth
Всё состояние лежит в одной MongoDB: планеты, легионы, события, изображения в GridFS и пользователи better-auth. Новая функция не вводит второе хранилище и не дублирует данные вне базы.

### II. Admin-Only Writes and Sensitive Reads
Все записи в API закрыты глобальным `AdminGuard` (401 без сессии, 403 без роли `ADMIN`). Выгрузка данных целиком считается чувствительным чтением и закрывается тем же guard. Клиент скрывает админские действия от остальных пользователей, но защита обеспечивается сервером.

### III. Validated Input
Входные данные проверяются DTO через `class-validator`. Неверный ObjectId даёт 400, отсутствующий объект 404. Ошибки сервера клиент показывает пользователю через `apiErrorMessage` и toast.

### IV. Same-Origin Client
Браузер обращается только к Next. Запросы к API идут через rewrite `/api/backend/*` с cookie сессии. Клиент не знает адрес NestJS.

### V. Minimal Change
Изменение затрагивает только нужные модули и повторяет стиль соседнего кода. Новые зависимости не добавляются, если задачу решает стандартная библиотека или уже используемый пакет.

## Quality Gates

- Сервер: `npm test` и `npm run build` в `server/`.
- Клиент: `npx tsc --noEmit` и `npm run build` в `client/`.
- Сквозная проверка на стеке `docker compose`: основной сценарий, ошибка и граница.
- `db-check` после изменений, которые пишут в базу.

## Governance

Constitution важнее остальных практик проекта. Изменение принципа требует новой версии и записи даты.
