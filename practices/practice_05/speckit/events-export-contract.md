# Контракт: экспорт событий в JSON

Общий контракт между спекой UI (`001-events-export-ui`) и спекой логики (`002-events-export-api`). Обе спеки ссылаются на него и не противоречат ему.

## Вызов

`GET /events/export` без параметров и тела. Клиент вызывает `/api/backend/events/export` same-origin с cookie сессии.

## Доступ

Только роль `ADMIN`. Глобальный `AdminGuard` пропускает GET без проверки, поэтому маршрут проверяет сессию и роль явно.

| ситуация | статус |
|---|---|
| нет сессии или сессия недействительна | 401 |
| роль не `ADMIN` | 403 |

Клиент показывает кнопку только `ADMIN`, но защиту обеспечивает сервер.

## Успешный ответ

Статус 200, заголовки:

- `Content-Type: application/json; charset=utf-8`
- `Content-Disposition: attachment; filename="events-YYYYMMDD.json"`, дата UTC

Тело:

```json
{
  "exportedAt": "2026-10-29T10:00:00.000Z",
  "events": [
    {
      "id": "string",
      "name": "string",
      "description": "string | null",
      "link": "string | null",
      "shots": ["string"],
      "place": {
        "id": "string",
        "name": "string",
        "size": 0,
        "top": 0,
        "left": 0,
        "ingamePosition": "string | null",
        "pic": "string | null",
        "description": "string | null"
      },
      "createdAt": "ISO-8601",
      "updatedAt": "ISO-8601"
    }
  ]
}
```

- Все события без фильтра, порядок `createdAt` по возрастанию, при равенстве по `id`.
- `shots` всегда массив, порядок сохраняется.
- Если планета события не найдена, `place` равен `null`, экспорт не падает.

## Пустой результат

200 и `events: []`. Клиент скачивает файл и показывает «События отсутствуют».

## Ошибки

Тело в формате NestJS: `{ "statusCode": number, "message": string | string[], "error": string }`.

| статус | когда | сообщение в UI |
|---|---|---|
| 401, 403 | нет сессии или роли | «Недостаточно прав: войдите как администратор» |
| 413 | событий больше 10 000 | «Слишком много событий для экспорта» |
| 5xx, сеть, невалидный JSON | прочие сбои | «Ошибка при экспорте событий» и `message` сервера, если есть |

Частичный файл при ошибке не отдаётся.

## Имя файла

Клиент берёт имя из `Content-Disposition`, без заголовка использует `events.json`.

## Решения при согласовании

| вопрос | UI до | логика до | решение |
|---|---|---|---|
| форма тела | массив | `{ exportedAt, events }` | `{ exportedAt, events }` |
| имя файла | `events.json` на клиенте | `Content-Disposition` | заголовок, запасное `events.json` |
| событие без планеты | не описано | 500, экспорт падает | `place: null` |
| лимиты и коды | 401, 403, прочее | 413 по числу и 50 MiB, 503 | 413 только по числу, 50 MiB и 503 убраны, сбои базы дают 5xx |
