# Tailwind Conventions (LuckySpin)

## Когда применять
- Вся вёрстка проекта LuckySpin: лобби, карточки игр, модалки спина, колесо бонуса.

## Как устроено
- Только утилитарные классы Tailwind; не создаём отдельных CSS/SCSS файлов.
- Единый визуальный язык: цветовая палитра, размеры, тени — из Tailwind config.
- Компонентные паттерны реализуем через композицию классов и небольшие UI-утилиты (clsx), без кастомных CSS.
- Респонсив и состояния (hover/focus/aria-*) — через модификаторы Tailwind.

## Шаги
1. Дизайн разбиваем на атомы: контейнеры, кнопки, карточки.
2. Используем преднастроенные токены tailwind.config для цветов/spacing/типографики.
3. Сложные композиции оформляем как небольшие компоненты с готовыми классами.
4. Проверяем мобильную и десктопную адаптивность.
5. Покрываем критичные стили тестами визуального поведения (классы на состоянии).

## Запрещено
- Создание .css/.scss файлов для стилей компонентов.
- Inline-стили, кроме динамически вычисляемых, где это оправдано.
- Произвольные цвета/размеры вне токенов Tailwind без согласования.
- Глобальные стили, влияющие на все компоненты, без необходимости.
