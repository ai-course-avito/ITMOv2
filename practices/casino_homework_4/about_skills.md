test-driven-development: Описывает цикл Red → Green → Refactor для фич и багфиксов с контролем времени и RNG. Помогает сначала формализовать поведение в тестах, а затем писать минимальный код и безопасно рефакторить.

writing-good-tests: Правила детерминированных, читаемых тестов (AAA), с примерами для спина, бонуса и баланса. Помогает избегать флаки-тестов и лишней привязки к реализации.

react-best-practices: Функциональные компоненты, строгий TypeScript без any, глобальный стейт в Zustand, эффекты только для I/O, мемоизация по необходимости. Обеспечивает предсказуемость, читаемость и производительность UI.

tailwind-conventions: Только утилитарные классы Tailwind, единый визуальный язык из tailwind.config, responsive и состояния через модификаторы. Исключает разрастание кастомного CSS и поддерживает единый стиль интерфейса.
