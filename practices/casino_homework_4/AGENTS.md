# AGENTS.md

## Проект

**LuckySpin** — сайт-казино на виртуальных монетах.
MVP: две фичи, без реальных денег.

**Цель:** работающее демо, которое можно показать.

## Фичи MVP

1. **Лобби автоматов** — сетка игр, клик → запуск, ставка → спин → результат.
2. **Ежедневный бонус** — колесо фортуны, раз в день выдаёт монеты.

Всё. Больше в MVP ничего нет.

## Что НЕ делаем

- Реальные платежи, KYC, вывод.
- Лидерборды, кланы, профили, ачивки.
- Backend, базы данных, авторизацию.
- Live-казино, крипту.

Если задача про это — стоп, спросить.

## Стек

- **Frontend:** React + Vite + TypeScript
- **Стили:** Tailwind
- **Состояние:** Zustand (баланс монет, история)
- **Хранение:** localStorage (баланс, дата последнего бонуса)
- **Тесты:** Vitest
- **Линт:** ESLint + Prettier
