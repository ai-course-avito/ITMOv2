# Mini Shop · Практика 8

Покупатель загружает каталог, выбирает товар, вводит данные учебной учётной записи и получает номер заказа. Приложение обращается к существующему API из ветки `practice_6`. Каталог, цена и создание заказа определяются сервером.

## Запуск

Требования: Node.js 22.12+ и запущенный Mini Shop на `127.0.0.1:8066` (практика 6). Откройте API в отдельной рабочей копии ветки `practice_6` и запустите `python3 service.py --port 8066` из её каталога `practices/practice_06/lab`. В этой папке выполните `npm ci`, затем `npm run dev`. Vite маршрутизирует `/api/*` в локальный Mini Shop.

Клиентские тесты: `npm test`. Сборка: `npm run build`. Для развёртывания сборки нужен тот же маршрут `/api` к серверу. Используйте только учебную учётную запись из README лаборатории.

## Макет и реализация

[Прототип](design/prototype.svg) показывает форму и состояния. Bootstrap используется для карточки, полей, кнопок, алерта и адаптивной сетки. Общие цвета и видимый фокус заданы в `src/style.css`. При отправке заблокированы кнопка и обработчик формы, включая повторный Enter. Пароль очищается после успеха.

Codex использован для трёх задач. Запрос для макета: «Покажи каталог, форму заказа, ожидание, успех и ошибку». Запрос для интерфейса: «Используй Bootstrap и подключи GET /products, POST /login и POST /orders». Запрос для тестов: «Подмени ответы API для пустого каталога, ошибки и задержки, проверь номер заказа и единственный запрос при повторной отправке». При сверке с контрактом цена исключена из тела заказа, вместо неё показывается цена из ответа сервера.
