# Проверки

- `npm test`: 6 клиентских тестов пройдено. Покрыты загрузка, пустой каталог, ошибка и повторная загрузка, обязательные поля, ошибка входа, успешный заказ и блокировка повторной отправки.
- `npm run build`: сборка Vite прошла.
- Браузер с реальным Mini Shop из ветки `practice_6`: первый запрос с неверным паролем показал сообщение об ошибке, после исправления получено «Заказ №3 оформлен. Стул · 5 000 ₽».
