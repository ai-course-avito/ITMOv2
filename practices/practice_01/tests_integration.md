# Integration-проверки

| Связь компонентов | Что может сломаться | Как воспроизводим | Ожидаемый результат | Evidence |
|---|---|---|---|---|
| API → ReviewService | Нет поля `diff` в теле запроса приводит к 500 (KeyError) | POST `/api/reviews` с телом `{}` или `{ "text": "..." }` | 422 Unprocessable Entity от уровня API; обработчик не падает | TRAINING_PR.diff: app/api.py L35-38 — используется `payload["diff"]` без валидации |
| ReviewService → LLM | Ошибка/таймаут LLM «пробивает» наружу или зависает запрос | Инжектировать тестовый LLM, который бросает `TimeoutError` или задерживается >10s; вызвать `POST /api/reviews` с валидным `diff` | 502/503 с контролируемым телом ошибки; время ответа ≤10s | CASE.md: REL-1; TRAINING_PR.diff: app/review_service.py L21 — нет таймаута/обработки ошибок |
| API → OpenAPI | В /docs нет описания `/api/reviews` или схема не согласована | GET `/openapi.json` или открыть `/docs`; проверить наличие пути `/api/reviews` и схемы ответа | `/api/reviews` присутствует в OpenAPI; схема ответа соответствует OUT-1: объект с `summary`, `risks` (≤3, элементы с `file`, `line`, `evidence`, `risk`) и `checks` | TRAINING_PR.diff: app/api.py L35-38 — добавлен `@app.post("/api/reviews")` |
| Логирование (OBS-1) | В логи попадает содержимое `diff` или ответ LLM | Отправить `POST /api/reviews` с `diff`, содержащим тестовый секрет; собрать логи приложения | Логи содержат только `request_id`, длительность и статус; нет `diff` и текста ответа модели | CASE.md: OBS-1; TRAINING_PR.diff — отсутствует явное логирование, что снижает риск утечки |
