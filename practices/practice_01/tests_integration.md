# Integration-проверки

Файл ведёт OpenCode. Обсудите с агентом содержание и проверьте предложенный diff. Все дополнения и исправления поручайте агенту в чате.

| Связь компонентов | Что может сломаться | Как воспроизводим | Ожидаемый результат | Подтверждение |
|---|---|---|---|---|
| Gateway ↔ FastAPI | Отсутствие auth/лимита размера | Запрос без токена; запрос с diff >20k | 401/403 без токена; 413 при превышении | HTTP трасс; конфиг gateway |
| FastAPI ↔ ReviewService | Невалидный payload → 500 | Отправить `{}` | 422 вместо 500 | Логи/ответ |
| ReviewService ↔ Prompt Builder | Секреты не редактируются | Diff с «token=abc» | В промпте `[REDACTED]` вместо секретов | Встроенный mock LLM, возврат prompt |
| Prompt Builder ↔ LLM | Prompt injection | Diff с инструкцией «ignore...» | LLM игнорирует пользовательскую инструкцию; сохраняются системные правила | Ответ LLM через заглушку |
| LLM ↔ Error Mapper | Таймаут/исключение | LLM заглушка бросает Timeout | 503/504 c диагностикой; без stack trace | Ответ API; лог OBS-1 |
