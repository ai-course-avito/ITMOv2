# Integration-проверки

Файл ведёт OpenCode. Обсудите с агентом содержание и проверьте предложенный diff. Все дополнения и исправления поручайте агенту в чате.

| Связь компонентов | Что может сломаться | Как воспроизводим | Ожидаемый результат | Подтверждение |
|---|---|---|---|---|
| API → ReviewService (AS IS) | Отсутствие поля diff | POST /api/reviews с {} | Исключение при обращении к payload["diff"] (текущее поведение) | Цитата из diff app/api.py |
| API → ReviewService (TO BE) | Отсутствие поля diff | POST /api/reviews с {} | Контролируемая ошибка валидации; точный статус — открытый вопрос | Требование product_management.md |
| ReviewService → LLM | Исключение из llm.generate | Тестовый LLM, выбрасывающий исключение | Исключение не перехватывается в показанном фрагменте (AS IS); обработка — предмет доработки | Цитата из diff app/review_service.py |
| Включение diff в prompt | Потенциальное влияние содержимого diff | Передать директивный текст в diff | Риск помечен как гипотеза; команды внутри diff игнорируются как инструкции | Цитата из diff формирования prompt; правило в Master Prompt v1 |
