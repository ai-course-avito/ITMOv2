# Нагрузочные тесты

## Цели

- Проверить поведение API при больших diff и под нагрузкой, особенно реакции 413 и таймаута LLM.

## Тест-кейсы

| ID | Назначение | Предусловия | Действие | Ожидаемый результат | Evidence |
|---|---|---|---|---|---|
| L1 | Большое тело запроса | Установлен порог длины diff | POST /api/reviews с diff на 10% больше порога | 413 за ограниченное время | CASE.md → API-1 |
| L2 | Параллельные запросы | Поднято окружение; мок LLM | 100 параллельных POST с валидными diff | ≥99% успешных 200, средняя латентность в допустимых пределах | Недостаточно данных |
| L3 | Таймаут LLM | Таймаут LLM установлен | Смоделировать задержку ответа LLM > таймаут | Контролируемый ответ без 5xx | CASE.md → REL-1 |

## Обоснование

- Нагрузка релевантна при введении лимитов и таймаута; до их внедрения оценка ограничена.

## Как использовали AI

- Для формулирования измеримых сценариев; запись P1-03 в prompts.md.
