# E2E-проверки

| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Evidence |
|---|---|---|---|---|
| Позитивный | Есть валидный JSON с `diff` ≤ 20000 | Отправить POST `/api/reviews` с телом | 200 OK и JSON по OUT-1: `summary`, `risks`≤3, `checks` | Проверка структуры ответа по схеме OUT-1 |
| Негативный | Подготовить `diff` длиной > 20000 символов | Отправить POST `/api/reviews` | 413 Payload Too Large | Код ответа 413 |
| Граничный | `diff` содержит тестовые секреты (token, пароль, PEM) | Отправить POST `/api/reviews` | В промпте к LLM секреты заменены на `[REDACTED]`; при ошибке провайдера 502, при таймауте >10с — 504 | Наличие `[REDACTED]` в переданном промпте; коды 502/504 при соответствующих инъекциях сбоев |

- Тип промпта: Master Prompt v2
- Строка в [`prompts.md`](prompts.md): P1-04
- Что проверили и исправили сами: сохранили точную структуру таблицы и учли коды 200/413/502/504 и требования SEC-1, OUT-1.
