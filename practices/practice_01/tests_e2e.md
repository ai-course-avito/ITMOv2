# E2E-проверки

| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Evidence |
|---|---|---|---|---|
| Позитивный: корректный небольшой diff | Сервис с реализованным контрактом; мок LLM | Отправить POST `/api/reviews` с `diff` длиной 100 символов | Ответ содержит `summary`, `risks` (≤3), `checks`; 2xx статус | планируемый e2e-тест; evidence после реализации |
| Негативный: отсутствует поле diff | Сервис с валидацией | Отправить POST `/api/reviews` с `{}` | 422 Unprocessable Content; логи без diff | планируемый e2e-тест; evidence после реализации |
| Негативный: пустой или пробельный diff | Сервис с валидацией | Отправить `{"diff": "   "}` | 422; LLM не вызывается | планируемый e2e-тест; evidence после реализации |
| Граничный: diff длиной 20001 символ | Сервис с проверкой длины | Отправить POST `/api/reviews` с `diff` длиной 20001 | 413 Content Too Large; LLM не вызывается | планируемый e2e-тест; evidence после реализации |
| Секреты: редактирование | Сервис с redaction | Отправить diff с `token=abc123` | В prompt секрет заменён на `[REDACTED]` | план проверки на тестовом окружении; evidence после реализации |
| Сбой LLM: таймаут | Мок LLM с задержкой > 10s | Отправить POST `/api/reviews` | HTTP 502; `error.code=LLM_UPSTREAM_ERROR`; без утечки деталей в логи | планируемый e2e‑тест; evidence после реализации |
