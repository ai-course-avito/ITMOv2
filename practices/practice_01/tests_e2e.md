# E2E-проверки

Файл ведёт OpenCode. Сквозные сценарии используют реальный FastAPI TestClient и мок‑LLM.

| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Подтверждение |
|---|---|---|---|---|
| Позитивный | Приложение запущено; LLM возвращает валидный ответ | POST валидного ReviewRequest | 200 и ReviewResponse с ≤3 рисками | pytest e2e: status 200, валидация схемы |
| Негативный | Невалидный JSON (без diff) | POST | 422 с подробностями | pytest e2e: status 422 |
| Граничный | LLM кидает TimeoutError | POST валидного ReviewRequest | 502 Bad Gateway | pytest e2e: status 502 и тело с кодом |

## Как использовали AI

- Для чего: зафиксировать сквозные сценарии, подтверждающие TO BE.
- Тип промпта: master prompt.
- Строка в [`prompts.md`](prompts.md): P1-02, P1-03.
- Что проверил студент и какие исправления поручил агенту: статусы и структура ответа выровнены с ADR и use cases.
