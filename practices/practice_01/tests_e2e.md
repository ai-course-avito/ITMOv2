# E2E-проверки

| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Evidence |
|---|---|---|---|---|
| Позитивный | Сервис поднят, мок LLM отвечает | Разработчик шлет `POST /api/reviews` с diff из `TRAINING_PR.diff` | `summary` + до 3 `risks` с evidence + `checks`, решение принимает человек | E2E-прогон, сверка с `P1-02` |
| Негативный | Сервис поднят | Шлем `{}` без `diff` и diff с `token=test-123` | `400/422` без падения; при валидном diff секреты заменены на `[REDACTED]` | E2E-прогон, `SEC-1/API-1` |
| Граничный | Сервис поднят, мок LLM висит 30s | Шлем валидный diff при зависшем LLM | Контролируемый ответ по `REL-1` (не 500, не зависание), в логе только `request_id`/статус | E2E-прогон, `REL-1/OBS-1` |

## Как использовали AI

- Строка в [`prompts.md`](prompts.md): `P1-02`
- Что проверили и исправили сами: граничный кейс с висящим моком 30s придумал сам — в `P1-02` этого не было; решение оставил за человеком, иначе нарушил бы `SCOPE-1`
