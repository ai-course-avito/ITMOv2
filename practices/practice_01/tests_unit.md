# Unit-проверки

| Требование или правило | Что проверяем изолированно | Вход | Ожидаемый результат | Evidence |
|---|---|---|---|---|
| SEC-1 | фильтр секретов в `ReviewService` перед формированием prompt | diff со строкой `api_token=secret123` и `password=super` | в prompt, уходящем во внешний LLM, вместо токена и ключа `[REDACTED]`; сам diff не изменён для ответа пользователю | тест: DummyLLM записывает полученный prompt; содержимого секретов в нём нет |
| API-1 | проверка длины diff на границе лимита | diff длиной 20 000 символов; diff длиной 20 001 символ | 20 000 → допускается; 20 001 → отклоняется (исключение/413 на уровне сервиса) | тест с `len(diff)` ровно на границе |
| REL-1 | timeout вызова LLM | LLM-заглушка спит 15 с; порог 10 с | через ≤10 с сервис возвращает контролируемую ошибку, исключение не пробрасывается наружу | тест: таймер вокруг `review()`, ошибка содержит причину `timeout` |
| REL-1 | ошибка LLM не превращается в 500 | LLM-заглушка кидает `RuntimeError` | `review()` возвращает контролируемый ответ об ошибке | тест: `assert` на отсутствие исключения из `review()` |
| OUT-1 | структура результата | любой корректный diff | ответ содержит `summary` (str), `risks` — массив ≤3 объектов с полями `file`, `line`, `evidence`, `risk`, и `checks` — массив строк | проверка ключей и типов JSON-ответа |
| QA-1 | риск без evidence не включается | diff без нарушений; ответ LLM содержит надуманный риск | в `risks` ноль элементов, надуманный риск отфильтрован | список рисков сверяется со строками diff/правилами |
| OBS-1 | логирование не содержит содержимого | logger-заглушка записывает всё, что пишет сервис | в записях только `request_id`, длительность, статус; нет diff и текста ответа | поиск в записях лога строки из diff и из ответа |

Ниже — иллюстрация типового unit-теста SEC-1 (на вымышленной структуре, чтобы проверку можно было воспроизвести):

```python
class DummyLLM:
    def __init__(self):
        self.last_prompt = ""

    def generate(self, prompt: str) -> str:
        self.last_prompt = prompt
        return "no problems"

def test_secrets_are_redacted_in_prompt():
    llm = DummyLLM()
    service = ReviewService(llm)          # с включённым фильтром SEC-1
    service.review("api_token=secret123\npassword=super\n")
    assert "secret123" not in llm.last_prompt
    assert "super" not in llm.last_prompt
    assert "[REDACTED]" in llm.last_prompt
```
