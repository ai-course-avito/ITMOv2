# Unit-проверки

Файл ведёт OpenCode. Обсудите с агентом содержание и проверьте предложенный diff. Все дополнения и исправления поручайте агенту в чате.

| Требование или правило | Что проверяем изолированно | Вход | Ожидаемый результат | Подтверждение |
|---|---|---|---|---|
| Текущее поведение (AS IS): отсутствие поля diff | Доступ по ключу без проверки вызывает исключение | payload = {} | Исключение при обращении к payload["diff"] (текущее поведение из diff) | Цитата из diff app/api.py: `review_service.review(payload["diff"])` |
| Желаемое поведение (TO BE): валидация входа | Проверка контролируемой ошибки валидации | payload = {} | Контролируемый отказ валидации; точный статус — открытый вопрос | Требование из product_management.md и Master Prompt v1 |
| Структура результата | Наличие поля comment в ответе | строка diff | Возвращается dict с ключом "comment" | Цитата из diff app/review_service.py: `return {"comment": answer}` |
| Разделение дефектов и рисков | Метка «дефект/риск» в отчёте ассистента | искусственный пример | Пункты помечены корректно | Master Prompt v1: раздел о форматах и DoD |
