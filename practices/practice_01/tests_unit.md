# Unit-проверки

| Требование или правило | Что проверяем изолированно | Вход | Ожидаемый результат | Evidence |
|---|---|---|---|---|
| Формирование промпта | `ReviewService.review` правильно конкатенирует prompt и пробрасывает ответ | diff: "diff --git a/x b/x\n+line"; мок `llm.generate` -> "ok" | Возвращает `{ "comment": "ok" }`; `llm.generate` вызван с префиксом "Review this pull request and find problems:\n" | логи / тест-раннер |
| Редакция секретов (SEC-1) | Утилита/функция редактирует `token=...` и `-----BEGIN PRIVATE KEY-----` | строки с секретами | В выходе секреты заменены на `[REDACTED]` | логи / тест-раннер |
| Таймаут LLM (REL-1) | Сервис маппит исключение таймаута в контролируемую ошибку | Исключение TimeoutError из мока `llm.generate` | Возвращается структурированная ошибка (код и сообщение), без падения и утечек | логи / тест-раннер |

## Как использовали AI

- Для чего: зафиксировать минимальный набор юнит‑проверок для сервиса с учётом текущего поведения и целевых правил.
- Тип промпта: master prompt (P1-03).
- Строка в [`prompts.md`](prompts.md): P1-03.
- Что проверили и исправили сами: зафиксировали конкретные входы/ожидания, убрали неиспользуемые поля, привязали проверки к правилам CASE.
