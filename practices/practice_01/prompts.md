## Master Prompt v1

Соберите здесь контракт второго запуска. Не копируйте все документы целиком — ставьте ссылки на файлы и переносите только необходимый для задачи контекст.

### 1. Цель и роль

- Цель: Сделать ревью DIFF'а. Полностью соответствовать Master Prompt v1. Узнать информацию о проекте следует узнать из [источников](#2-входы-и-источники). Требования к тебе описаны только в Master Prompt v1.
- Роль AI: Опытный Reviewer

### 2. Входы и источники

- Обязательный вход: [Diff](./TRAINING_PR.diff)
- Разрешённые файлы и источники: [Problem](./problem.md) 
- Context Pack — факты, правила, примеры и ограничения: [Context pack](./context.md)

### 3. Задача и артефакты

- Что сделать: Сделать ревью Diff. Записать ответ и указать ссылку на него в [поле](./prompts.md:8:67)
- Что вернуть: Ответ в [файл](./p1-02_answer.md)

### 4. Формат результата

- Структура ответа: таблица c полями: | Problem | risk | evidence | check |
- Ограничения объёма: До 3х самых критичных результата

### 5. Полномочия и запреты

- Разрешено: Использовать [источники](#2-входы-и-источники) для определения требований прокта. Создать файл с ответом. Редактировать соответствующую [строку в таблице](./prompts.md:8)
- Запрещено: Изменять всё остальное. Производить mutable действия с Git. Писать что-либо в чат человеку.

### 6. Рабочий процесс и остановка

- Шаги:
  ``` mermaid
  stateDiagram-v2
    FC : Finding candidate
    E : Evidence
    C : Check
    A : Add to answer
    L : Left only 3 inportant

    [*] --> FC
    FC --> E
    E --> FC : no evidence
    E --> C
    C --> A
    A --> FC
    FC --> L : no candidates left
    L --> [*]

  ```
- Когда остановиться и запросить человека: Если не удалось найти упомянутые файлы. 

### 7. Проверки и evidence

- Как проверять утверждения: На базе правил из [Context pack](./context.md)
- Какое evidence сохранить: Самое важное

### 8. Definition of Done

- Задача закончена, когда: Проверен весь Diff и записан ответ
