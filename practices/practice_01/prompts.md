## Master Prompt v1

Соберите здесь контракт второго запуска. Не копируйте все документы целиком — ставьте ссылки на файлы и переносите только необходимый для задачи контекст.

### 1. Цель и роль

- Цель: провести повторное ревью файла `practices/practice_01/TRAINING_PR.diff` по 6 критериям.
- Роль AI: Code Reviewer, фиксировать только факты из диффа, без домыслов.

### 2. Входы и источники

- Обязательный вход: `practices/practice_01/TRAINING_PR.diff`.
- Разрешённые файлы и источники: `prompts.md`, `context.md`, `problem.md` в `practices/practice_01/`.
- Context Pack — факты, правила, примеры и ограничения:
  - Использовать только факты из диффа; не делать предположений вне кода (источник: постановка задачи).
  - Если дифф отсутствует — остановиться (источник: постановка задачи).

### 3. Задача и артефакты

- Что сделать: проанализировать дифф, найти ошибки по 6 критериям (синтаксис, логика, ТЗ, безопасность, читаемость, структура), предложить точечные исправления; затем обновить `prompts.md`, `context.md`, `problem.md`.
- Что вернуть: список ошибок в формате «файл + строка, проблема, исправление», итог (зелёный/жёлтый/красный), рекомендации.

### 4. Формат результата

- Структура ответа: пункты по каждому найденному багу с указанием файла и строки в диффе, затем итоговая оценка и рекомендации.
- Ограничения объёма: только факты, подтверждённые строками из диффа.

### 5. Полномочия и запреты

- Разрешено: ссылаться на строки диффа; давать минимальные правки к показанному коду; редактировать `prompts.md`, `context.md`, `problem.md`.
- Запрещено: выдумывать несуществующие файлы/контекст; менять файлы кода вне диффа; делать выводы, не подтверждённые диффом.

### 6. Рабочий процесс и остановка

- Шаги:
  1. Открыть `TRAINING_PR.diff` и проанализировать изменения.
  2. Зафиксировать проблемы по 6 критериям с привязкой к строкам диффа.
  3. Сформировать предложения по исправлению (минимальные правки).
  4. Обновить `prompts.md`, `context.md`, `problem.md` по результатам.
- Когда остановиться и запросить человека: если `TRAINING_PR.diff` отсутствует или содержит конфликтные/неполные hunks.

### 7. Проверки и evidence

- Как проверять утверждения: каждое утверждение подкреплять ссылкой на конкретную строку/фрагмент диффа.
- Какое evidence сохранить: ссылки на файлы и номера строк диффа; цитаты проблемных фрагментов.

### 8. Definition of Done

- Задача закончена, когда: выданы все находки по 6 критериям с привязкой к строкам диффа; сформирован итог (зелёный/жёлтый/красный) и рекомендации; обновлены `prompts.md`, `context.md`, `problem.md`.
