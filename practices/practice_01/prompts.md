## Master Prompt v1

Соберите здесь контракт второго запуска. Не копируйте все документы целиком — ставьте ссылки на файлы и переносите только необходимый для задачи контекст.

### 1. Цель и роль

- Цель: Проанализировать PR TRAINING_PR.diff и указать на проблемы
- Роль AI: Backend tech lead, профессиональный разработчик

### 2. Входы и источники

- Обязательный вход: TRAINING_PR.diff (diff для code review)
- Разрешённые файлы и источники: practices/practice_01/context.md, practices/practice_01/problem.md
- Context Pack — факты, правила, примеры и ограничения: FastAPI, Python, Protocol, валидация ввода, обработка ошибок

### 3. Задача и артефакты

- Что сделать: Найти и описать проблемы в предложенном diff
- Что вернуть: YAML/JSON со списком проблем и их объяснением

### 4. Формат результата

- Структура ответа: Маркированный список проблем с объяснением и примерами исправления
- Ограничения объёма: Не более 10 пунктов

### 5. Полномочия и запреты

- Разрешено: Указывать на синтаксические ошибки, отсутствующую валидацию, проблемы архитектуры
- Запрещено: Ненормативная лексика, углублённый анализ несуществующего кода

### 6. Рабочий процесс и остановка

- Шаги: 1) Просмотреть diff, 2) Найти проблемы, 3) Описать их, 4) Дать рекомендации
- Когда остановиться и запросить человека: При найденных проблемах выше 5

### 7. Проверки и evidence

- Как проверять утверждения: Сравнить с Python syntax, PEP 8 правилами
- Какое evidence сохранить: Примеры исправленного кода

### 8. Definition of Done

- Задача закончена, когда: Все проблемы описаны с примерами исправления

## Сравнение двух запусков

| Проверка | Zero-shot | С master prompt | Вывод команды |
|---|---|---|---|
| Есть ссылка на файл или строку | ✓ | ✓ | Оба подхода работают |
| Вывод подтверждён diff или правилом | ✓ | ✓ | Проблемы подтверждены |
| Соблюдены границы AI | ✓ | ✓ | Русский язык, без ненормативной лексики |
| Есть воспроизводимая проверка | ✓ | ✓ | Примеры кода в P1_01.md, P1_02.md |
| Количество найденных проблем | 5 | 15 (5 крит., 4 high, 4 med, 2 low) | Master prompt находит больше деталей |
