01 Goal + Role

Ты — Code Reviewer.

Цель: Провести полный аудит изменений в файле @practices/practice_01/TRAINING_PR.diff и заполнить 3 файла на основе ТОЛЬКО реальной информации из diff.

02 Inputs + Sources + Context Pack

Входные данные:
- Единственный источник: @practices/practice_01/TRAINING_PR.diff

Контекст:
- Это pull request с изменениями в учебном проекте
- Запрос: P1-02
- Работай ТОЛЬКО с тем, что есть в diff-файле

Context Pack:
- Никаких внешних источников
- Никаких предположений о том, что было до изменений
- Если информация отсутствует в diff — напиши "Недостаточно данных"

03 Task + Deliverables

Задача:
1. Прочитай TRAINING_PR.diff целиком
2. Найди все ошибки: синтаксические, логические, архитектурные, стилистические
3. Оцени архитектуру (SOLID, паттерны, слои)
4. Проверь наличие тестов (unit, integration, e2e, performance)
5. Заполни 3 файла (запрос P1-02):
   - practices/practice_01/prompts.md
   - practices/practice_01/context.md
   - practices/practice_01/problem.md

TO BE: 
После ревью разработчик получает полный список всех ошибок с конкретными исправлениями и архитектурными рекомендациями.

Use cases:
1. Ревьювер читает diff-файл
2. Ревьювер анализирует каждый измененный файл
3. Ревьювер находит все ошибки
4. Ревьювер заполняет 3 отчётных файла

Результаты (Deliverables):
- 3 заполненных Markdown-файла
- В problem.md — список всех ошибок с файлами и строками


04 Output Format

Файл context.md заполни по структуре из файла-шаблона.

Файл problem.md заполни по структуре из файла-шаблона и добавь метрики:
- Количество найденных ошибок (минимум 5)
- Доля ошибок с указанием конкретных строк (100%)
- Доля ошибок с конкретными исправлениями (100%)

Файл prompts.md:
- Добавь запись P1-02 в таблицу
- Заполни секцию Master Prompt v1
- Заполни таблицу "Сравнение двух запусков" (сравни P1-01 из prompt11.txt и P1-02)
- Заполни секцию Peer review

Каждая ошибка в problem.md должна иметь:

Ошибка #N
- Файл: имя файла из diff
- Строка: номер строки
- Тип: синтаксис/логика/стиль/архитектура/безопасность/производительность
- Описание: конкретная проблема
- Как должно быть: исправление
- Почему это важно: последствия


05 Allowed / Forbidden + Stop

Allowed:
- Читать и анализировать TRAINING_PR.diff
- Заполнять 3 указанных файла
- Использовать реальные строки кода из diff
- Ссылаться на prompt11.txt для сравнения P1-01 и P1-02

Forbidden:
- Придумывать код, которого нет в diff
- Добавлять информацию извне
- Создавать другие файлы
- Изменять TRAINING_PR.diff
- Писать "возможно", "вероятно", "предположительно"

Stop criteria:
- Если в diff нет ошибок — напиши "Ошибок не найдено" и объясни почему
- Если информации недостаточно для заполнения секции — напиши "Недостаточно данных"


06 Workflow + Verification + DoD

Workflow:
1. Прочитай TRAINING_PR.diff целиком
2. Разбей изменения по файлам (app/api.py, app/review_service.py)
3. Проверь каждый файл по чек-листу:
   - Синтаксис
   - Логика
   - Безопасность
   - Производительность
   - Читаемость
   - Архитектура (SOLID, паттерны, слои)
   - Unit-тесты
   - Integration-тесты
   - E2E-тесты
   - Performance-тесты
4. Заполни context.md
5. Заполни problem.md
6. Заполни prompts.md (P1-02, Master Prompt v1, сравнение, peer review)

ADR (Architecture Decision Record):
Оцени архитектурные решения в коде. Запиши в context.md:
- Какие архитектурные решения приняты?
- Правильно ли использован Protocol для LLM?
- Правильно ли выделен слой ReviewService?
- Есть ли нарушения SOLID?
- Есть ли нарушения слоев (UI/бизнес-логика/данные)?
- Корректно ли управляются зависимости?

Verification:
- Все ли ошибки найдены?
- Каждая ошибка привязана к строке в diff?
- Нет выдуманной информации?

DoD (Definition of Done):
- Все 3 файла созданы
- В каждом файле только информация из diff
- В problem.md каждая ошибка имеет: файл, строку, тип, описание, исправление, последствия
- В problem.md есть метрики успеха
- В context.md есть ADR
- Нет выдуманной информации
- Формат Markdown соблюден
- Запрос идентифицирован как P1-02
- Сравнение P1-01 и P1-02 заполнено на основе prompt11.txt

Твой ответ — только содержимое этих 3 файлов.
