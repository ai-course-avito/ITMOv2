## Context Pack для первого рабочего сценария

### Факты и правила

- Вход `payload` для POST `/api/reviews` не валидируется схемой и типизирован как `dict` (app/api.py:36–37).
- Эндпоинт и сервис синхронные; LLM-вызов может быть I/O-bound, что блокирует обработчик.
- Промпт формируется как f-string из raw diff без тримминга/границ.

### Формат входа и результата

- Вход: JSON объект с ключом `diff` (строка); Результат: `{ "comment": string }`.

### Ограничения и запрещённые действия

- Не допускать лишней риторики; приводить 3–5 подтверждённых фактов.

### Хороший пример

- Проблема с ссылкой на строки diff и правило из FastAPI.

### Плохой пример

- Общее рассуждение без указания строк diff.
### Что пока неизвестно

- Ограничения по времени отклика, требования к асинхронности, SLA.
