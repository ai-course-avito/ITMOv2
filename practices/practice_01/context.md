## Context Pack для первого рабочего сценария

### Факты и правила

- Вход: JSON-объект с обязательным строковым полем `diff` (TRAINING_PR.diff:36).
- Выход: JSON-объект с единственным полем `comment: str` (TRAINING_PR.diff:22).
- `ReviewService.review` не валидирует и не ограничивает содержимое `diff` перед вставкой в промпт (TRAINING_PR.diff:19-21).
- `LLM.generate` — единственная точка вызова внешней модели, определена как `Protocol` без гарантий обработки ошибок (TRAINING_PR.diff:9-12).

### Формат входа и результата

- Вход: `POST /api/reviews`, тело `{"diff": "<строка с содержимым PR-диффа>"}`.
- Результат: `{"comment": "<текст ответа LLM>"}`, структура ответа LLM не регламентирована промптом.

### Ограничения и запрещённые действия

- Нельзя смотреть файлы за пределами `TRAINING_PR.diff`, `prompts.md`, `context.md`, `problem.md`.
- Нельзя редактировать код продукта — только таблицы в трёх указанных md-файлах.
- Промпт не задаёт ограничение длины входного diff и не санитизирует его — потенциальный вектор prompt injection (TRAINING_PR.diff:20).

### Хороший пример

`POST /api/reviews` с телом `{"diff": "diff --git a/foo.py ..."}` → сервис возвращает `{"comment": "Found: missing input validation at line 36..."}`.

### Плохой пример

`POST /api/reviews` с телом `{}` (без ключа `diff`) → необработанный `KeyError` в `app/api.py:37`, клиент получает 500 вместо понятной 4xx-ошибки.

### Что пока неизвестно

- Кто фактические пользователи эндпоинта (люди/CI) — не указано в diff.
- Реализация `app.dependencies.review_service` (как настроен `LLM`) — файл вне разрешённых источников.
- Ограничения по стоимости/квоте вызовов LLM — не описаны в разрешённых файлах.

## Как использовали AI

- Для чего: анализ `TRAINING_PR.diff` и извлечение фактов о продукте/процессе для Context Pack.
- Тип промпта: master prompt.
- Строка в [`prompts.md`](prompts.md): P1-02.
- Что проверили и исправили сами: убрали из ответа модели любые предположения о пользователях/бизнес-контексте, не подтверждённые diff, и явно перенесли их в раздел «Что пока неизвестно» вместо того, чтобы выдавать за факт.
