## Context Pack для первого рабочего сценария

### Факты и правила

- API добавляет POST /api/reviews, принимает JSON с ключом "diff" и возвращает dict с ключом "comment".
- ReviewService формирует промпт и вызывает LLM.generate.
- Протокол LLM определяет метод generate(self, prompt: str) -> str.

### Формат входа и результата

- Вход: JSON {"diff": str} для POST /api/reviews.
- Выход: JSON {"comment": str}.

### Ограничения и запрещённые действия

- Нельзя использовать нефактические допущения вне диффа.
- Нельзя изменять код вне представленного диффа при оценке.
