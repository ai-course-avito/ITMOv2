## Context Pack для первого рабочего сценария

### Факты и правила

- FastAPI приложение для review сервиса
- Protocol используется для типизации LLM интерфейса
- Эндпоинт /api/reviews принимает payload с diff

### Формат входа и результата

- Вход: JSON с полем "diff"
- Результат: JSON с полем "comment"

### Ограничения и запрещённые действия

- Нельзя игнорировать KeyError при доступе к payload["diff"]
- Нельзя возвращать сырой текст без валидации
- Необходимо следовать PEP 8 и Python best practices

### Хороший пример

```python
def generate(self, prompt: str) -> str: ...
```

### Плохой пример

```python
def generate(self, prompt: str) -> str:
    ...
```

### Что пока неизвестно

- Как именно будет использоваться сервис в production
- Какие требования к формату вывода
