## Context Pack для первого рабочего сценария

### Факты и правила

- app/review_service.py: добавлен метод ReviewService.review(diff) — собирает строковый промпт и вызывает LLM.generate; возвращает {"comment": answer}.
- app/api.py: добавлен POST /api/reviews, принимает dict payload и обращается к review_service.review(payload["diff"]).
- Протокол LLM определяет метод generate(prompt: str) -> str; вход diff вставляется напрямую в промпт без ограничений.

### Формат входа и результата

- Вход: JSON с ключом "diff" (строка), передаваемый в POST /api/reviews.
- Результат: JSON вида {"comment": string}, где comment — произвольный ответ LLM.

### Ограничения и запрещённые действия

- На основе diff: отсутствуют ограничения размера входа; отсутствует явная аутентификация/авторизация; отсутствует схема/валидация входа; ошибки не перехватываются.
