## Context Pack для первого рабочего сценария

### Факты и правила

- POST `/api/reviews` ожидает JSON с ключом `diff` и возвращает `dict[str, str]` с ключом `comment`.
- `ReviewService.review(diff: str)` формирует промпт: "Review this pull request and find problems:\n{diff}" и вызывает `llm.generate`.
- Аннотации `dict[str, str]` и `Protocol` указывают на использование Python ≥3.9.
- Импортируется `review_service` из `app.dependencies` (сам модуль в репозитории не показан).

### Формат входа и результата

- Вход: JSON `{ "diff": "..." }`.
- Результат: JSON `{ "comment": "<ответ LLM>" }`.

### Ограничения и запрещённые действия

- Нельзя полагаться на поля вне `diff` для этого эндпоинта.
- Нельзя выдумывать недостающие детали реализации вне видимого diff.

### Хороший пример

- Тело запроса: `{ "diff": "diff --git ..." }` -> 200 OK, тело `{ "comment": "..." }`.

### Плохой пример

- Тело запроса: `{}` -> KeyError `"diff"` в текущей реализации (рискует превратиться в 500).

### Что пока неизвестно

- Где определён и как инициализируется `app.dependencies.review_service`.
- Конкретный формат и ограничения LLM‑модели.
