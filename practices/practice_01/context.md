## Context Pack

### Факты

- PR добавляет эндпоинт `POST /api/reviews` в `app/api.py:35-37`
- Метод `ReviewService.review(diff)` в `app/review_service.py:13-16` формирует prompt из diff и вызывает внешний LLM
- LLM абстрагирован через `typing.Protocol` (app/review_service.py:4-6)
- Текущий ответ сервиса — `{"comment": <текст>}` (app/review_service.py:16)

### Правила репозитория (только релевантные для этого PR)

- **SEC-1**: перед отправкой во внешний LLM из diff удаляются токены, пароли, приватные ключи
- **API-1**: diff длиннее 20 000 символов отклоняется с HTTP 413
- **REL-1**: внешний LLM-вызов имеет timeout 10 секунд; ошибка превращается в контролируемый ответ
- **OUT-1**: ответ содержит `summary`, массив `risks` (max 3: file, line, evidence, risk) и массив `checks`
- **SCOPE-1**: сервис только советует; не пишет код и не выполняет действия в GitHub
- **QA-1**: риск включается в ответ, только если подтверждён строкой diff или правилом репозитория
- **OBS-1**: в лог пишутся только `request_id`, длительность и статус. Содержимое diff и ответа модели не логируется

Нерелевантные правила (не включать в артефакты):
- таблицы базы данных называются в snake_case
- все frontend-строки проходят через i18n

### Формат входа и результата

- Вход: `POST /api/reviews` с JSON `{"diff": "<diff>"}`
- Результат по OUT-1: `{"summary": "...", "risks": [{"file": "...", "line": ..., "evidence": "...", "risk": "..."}], "checks": ["..."]}`

### Ограничения и запрещённые действия

- diff > 20 000 символов → HTTP 413 (API-1)
- LLM timeout 10 секунд, ошибка → контролируемый ответ (REL-1)
- Обязательно удалять секреты из diff перед LLM (SEC-1)
- Сервис не делает commit/merge/approve (SCOPE-1)
- Риски только если подтверждены diff или правилом (QA-1)

секретов, что нарушает SEC-1. Проверка: передать diff с тестовым token

```

```

### Что пока неизвестно

- Какой именно LLM используется и откуда берётся токен доступа
- Точная версия Python в продакшене (dict[str, str] требует 3.9+)
- Есть ли аутентификация на эндпоинте
- Какой SLA и throughput ожидаются от сервиса
- Как хранятся секреты для LLM
