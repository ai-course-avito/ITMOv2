## Context Pack для первого рабочего сценария

### Факты и правила

- Язык и фреймворк: Python + FastAPI
- Хранение: PostgreSQL (таблицы локаций, пользователей, избранного и модерации)
- Доступ к БД: SQLAlchemy; миграции: Alembic (до первой dev-версии допускается переписывать первую миграцию)
- Кэш: Redis для частых запросов координат и результатов поиска (mobile-first латентность)
- Геокодинг: внешние API (например, OpenStreetMap/Nominatim) через httpx
- Строгая типизация DTO и схем: Pydantic
- Парадигма разработки: vibe-coding (AI пишет код, человек контролирует)
- Запрет на реализацию фронтенда в рамках данного репозитория

### Формат входа и результата

- REST API (JSON):
- Входы: запросы на поиск локаций по тайтлу/названию/тегам; запросы на получение координат локации; операции по управлению избранным
- Результаты: списки локаций с координатами/статусом верификации; отдельные координаты; подтверждение добавления в избранное

### Ограничения и запрещённые действия

- Строгая типизация моделей и ответов (Pydantic)
- Кэширование ответов в Redis, приоритет мобильной латентности
- Не реализовывать фронтенд и внешние UI-компоненты в этом проекте
