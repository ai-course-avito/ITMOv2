# Дизайн

- Фон: белый, без фоновых картинок, паттернов и теней.
- Цветовая схема по зонам интерфейса:
  - Красный - всё меню (добавление/удаление задачи).
  - Синий - настройки/параметры и служебная информация (слайдеры, баннер ошибки связи, статусный текст).
  - Фиолетовый - всё, что относится к графу (рёбра, базовые элементы канваса).
- Узлы графа: каждый связный кластер (см. docs/requirements.md) красится в один случайный цвет, общий для всех узлов этого кластера. Изолированная задача без связей - кластер из одной задачи, тоже получает свой случайный цвет.
- Этот файл не проверяется автотестами, только визуально.
