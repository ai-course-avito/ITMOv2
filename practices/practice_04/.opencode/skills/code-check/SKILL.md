# Code Check

Используй этот skill после добавления или изменения функциональности проекта.

## Цель

Убедиться, что изменение реализовано корректно и не нарушило существующее поведение.

## Порядок работы

1. Определи, какие файлы исходного кода были изменены.

2. Проверь, существует ли тест для новой функциональности.

3. Если теста нет, добавь его.

4. Запусти автоматическую проверку:

```bash
npm run check
