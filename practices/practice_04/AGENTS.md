# Project rules

## General

- Перед изменением кода изучи существующую структуру проекта.
- Делай только изменения, относящиеся к текущей задаче.
- Не изменяй посторонние файлы без необходимости.
- Не удаляй существующую функциональность, если этого явно не требует задача.

## JavaScript

- Проект использует JavaScript и ES Modules.
- Для небольших операций используй простые функции.
- Новая функциональность должна иметь автоматические тесты.
- Ошибочные входные данные должны обрабатываться, если это предусмотрено задачей.
