# Spec Delta

## Purpose

Позволяет пользователю практики 5 находить пункт отправления и назначения по названию города и выбирать конкретный аэропорт без знания IATA-кода.

## ADDED Requirements

### Requirement: Подсказки аэропортов по городу
Оба поля маршрута SHALL принимать название города и показывать отдельный вариант для каждого аэропорта этого города из поддерживаемого справочника. Каждый вариант SHALL содержать название города и различимое название аэропорта.

#### Scenario: Город с несколькими аэропортами
- **WHEN** пользователь вводит «Москва» в поле отправления или назначения
- **THEN** интерфейс показывает отдельные варианты «Москва — Шереметьево», «Москва — Домодедово» и «Москва — Внуково»

#### Scenario: Город с одним аэропортом
- **WHEN** пользователь вводит название поддерживаемого города с одним аэропортом
- **THEN** интерфейс показывает один вариант с названием города и аэропорта

#### Scenario: Совпадение без учёта регистра
- **WHEN** пользователь вводит название поддерживаемого города в другом регистре
- **THEN** доступны те же варианты аэропортов

### Requirement: Подтверждённый выбор для поиска
Поиск SHALL требовать выбора конкретного аэропорта в каждом поле. После выбора интерфейс SHALL показывать человеку город и аэропорт, а в запрос SHALL передавать IATA-коды выбранных аэропортов через существующий API.

#### Scenario: Поиск с выбранными аэропортами
- **WHEN** пользователь выбирает разные аэропорты отправления и назначения и нажимает «Найти билеты»
- **THEN** выполняется один поиск с кодами выбранных аэропортов и прежними датами и фильтрами

#### Scenario: Текст изменён после выбора
- **WHEN** пользователь меняет текст города или аэропорта после выбора варианта
- **THEN** прежний выбор сбрасывается, и поиск не запускается, пока пользователь не выберет вариант снова

#### Scenario: Неизвестный город или свободный IATA-код
- **WHEN** введённый текст не соответствует варианту справочника и пользователь пытается искать
- **THEN** интерфейс сообщает о необходимости выбрать аэропорт из списка и не отправляет запрос

#### Scenario: Одинаковые аэропорты
- **WHEN** в обоих полях выбран один и тот же аэропорт
- **THEN** сохраняется существующая ошибка о совпадении пунктов маршрута и поиск не запускается

### Requirement: Подсказки без поиска билетов
Показ и выбор подсказок SHALL работать локально без запросов к Ignav, без записи истории и без изменения результатов предыдущего успешного поиска до нажатия кнопки поиска.

#### Scenario: Ввод и выбор без отправки формы
- **WHEN** пользователь вводит город и выбирает аэропорт
- **THEN** не выполняется поиск билетов и не создаётся запись в истории

#### Scenario: Выбор с клавиатуры
- **WHEN** пользователь управляет полем маршрута с клавиатуры
- **THEN** он может выбрать один из показанных аэропортов без мыши
