# flight-price-order Specification

## Purpose

Позволяет пользователю практики 5 менять порядок уже найденных билетов по цене без повторного поиска и изменения остальных результатов.

## Requirements

### Requirement: Выбор порядка по цене
Интерфейс SHALL показывать над непустым списком результатов выбор «Сначала дешёвые / Сначала дорогие» и по умолчанию выбирать «Сначала дешёвые».

#### Scenario: Первое отображение результатов
- **WHEN** успешный поиск возвращает билеты с ценами 5000, 3000 и 4000
- **THEN** выбран порядок «Сначала дешёвые», а карточки показаны как 3000, 4000, 5000

#### Scenario: Выбор дорогих и возврат
- **WHEN** пользователь выбирает «Сначала дорогие» и затем «Сначала дешёвые»
- **THEN** карточки сначала показаны по убыванию цены, затем по возрастанию

### Requirement: Устойчивый локальный порядок
Сортировка SHALL сохранять взаимный порядок карточек с равной ценой из ответа сервера, не изменять состав карточек и исходные данные ответа. Переключение SHALL работать без нового запроса, запуска поиска или записи в историю.

#### Scenario: Равные цены
- **WHEN** ответ содержит две карточки с одинаковой ценой
- **THEN** эти карточки сохраняют взаимный порядок в обоих режимах

#### Scenario: Переключение без побочных действий
- **WHEN** пользователь несколько раз переключает порядок результатов
- **THEN** сетевые запросы и записи истории не добавляются, а параметры формы, сравнение цен и сведения о кеше сохраняются

### Requirement: Граничные состояния и новый поиск
Интерфейс SHALL скрывать выбор порядка при пустом ответе и сбрасывать его на «Сначала дешёвые» после каждого нового успешного поиска, сохраняя существующее отображение пустого ответа и ошибки.

#### Scenario: Пустой ответ
- **WHEN** успешный поиск возвращает пустой список
- **THEN** показано прежнее сообщение об отсутствии билетов, а переключатель скрыт

#### Scenario: Одна карточка
- **WHEN** успешный поиск возвращает одну карточку
- **THEN** эта карточка отображается корректно при любом выбранном порядке

#### Scenario: Новый успешный поиск
- **WHEN** после выбора «Сначала дорогие» выполняется новый успешный поиск
- **THEN** новый список показан по возрастанию цены и выбран порядок «Сначала дешёвые»

#### Scenario: Ошибка поиска
- **WHEN** поиск завершается ошибкой
- **THEN** сохраняется прежнее отображение ошибки
