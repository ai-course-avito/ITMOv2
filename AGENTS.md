# AGENTS.md

Стек и структура

- Язык: Python 3.x
- Тесты: `unittest`
- Линтер: нет (ruff не гарантирован). При необходимости добавить позже.
- Каталог практики: `practices/practice_04`

Команды проверки

- Единая команда: `bash practices/practice_04/scripts/check.sh`
- Внутри: `python -m unittest -q`

Контракты и примеры

- Тесты хранятся в `practices/practice_04/tests/`.
- Основной код — в `practices/practice_04/src/`.
- Нельзя изменять тесты, чтобы скрыть падение.

Нельзя менять

- Секреты и конфиги провайдеров в `opencode.json` трогать только для настройки hook; API ключи не коммитить.
- Не изменять другие практики и каталоги вне `practices/practice_04`.

Правило проверки

- После каждой правки запускать `bash practices/practice_04/scripts/check.sh`.
- Если проверка падает — исправить причину в коде, не менять тесты.

Git и секреты

- Делать атомарные коммиты с понятными сообщениями.
- Не выполнять destructive команды (`reset --hard`, force-push) без явного подтверждения.
- Не коммитить секреты, токены и приватные данные.
